A root $x^\star$ satisfies $\|x_0-x^\star\|\le R$ and $\langle F(x),x-x^\star\rangle\ge-(\rho/2)\|F(x)\|^2$ for all $x$, with $\rho\ge0$ and $\rho L_1\le1$. Queries return exact values or full Jacobians. The target is an integrable residual with $\int\|F(x_{\rm out}(\omega))\|\,dP(\omega)\le\varepsilon$, where $P$ is the execution law and $\varepsilon>0$.}\par\smallskip
