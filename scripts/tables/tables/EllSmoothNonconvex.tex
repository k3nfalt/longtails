\parbox{\linewidth}{\footnotesize Let $f:\mathbb R^d\to\mathbb R$ have a differentiable gradient with $\|\nabla^2 f(x)\|\le\ell(\|\nabla f(x)\|)$ and $f(x_0)-\inf f\le\Delta$. The profile $\ell$ is nondecreasing on $[0,\infty)$, positive on $(0,\infty)$, and $\ell(u)/u^\rho$ is nonincreasing for $u>0$ for some $\rho\in[0,2]$. Each query returns $(f(x),\nabla f(x))$ exactly. The target is $\mathbb E\|\nabla f(\hat x)\|\le\varepsilon$ for $\varepsilon>0$.}\par\smallskip
