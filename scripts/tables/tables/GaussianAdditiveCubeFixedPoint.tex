\parbox{\linewidth}{\footnotesize Let $C=[-R,R]^d$, $R\ge128\varepsilon>0$, $d\ge\lceil R/\varepsilon\rceil$, and $\sigma\ge0$. The map $T:C\to C$ is nonexpansive in $\ell_\infty$. Each query returns $T(x)+Z$ with independent draws $Z\sim\mathcal N(0,vI_d)$ and $\mathbb E\|Z\|_\infty^2\le\sigma^2$. A measurable adaptive randomized algorithm must return $\hat x\in C$ with $\mathbb E\|T(\hat x)-\hat x\|_\infty\le\varepsilon$, averaging over oracle and algorithm randomness.}\par\smallskip
