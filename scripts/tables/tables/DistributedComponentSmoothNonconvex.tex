\parbox{\linewidth}{\footnotesize On $\mathbb R^d$, $F=n^{-1}\sum_i f_i$ is bounded below, $F(x_0)-\inf F\le\Delta$, and $\nabla f_i$ is $L_i$-Lipschitz. Worker $i$ has a jointly measurable unbiased gradient oracle with variance at most $\sigma_i^2$. Samples are IID within workers and independent across workers. Workers compute in parallel, one batch per worker at a time, at $h_i>0$ time per sample. Computation and communication can overlap. The complete multiport network serves each directed link in FIFO order. An $m$-bit message takes $\ell+bm$ time. Here $n\ge1$, $L_i,\sigma_i,\Delta,\ell,b\ge0$, and $\varepsilon>0$. By the deadline, the execution returns a measurable $X$ with $\mathbb E_{\rm exec}\|\nabla F(X)\|^2\le\varepsilon^2$ and almost surely completes only finitely many events.}\par\smallskip
