\parbox{\linewidth}{\footnotesize On a real Hilbert space, $m\ge1$ differentiable convex components have $L$-Lipschitz gradients, $L>0$, and a common minimizer $x_\star$ with $\|x_0-x_\star\|\le R$, $R\ge0$. The oracle returns exact component gradients. The setup fixes cyclic gradient steps of size $1/L$; the target is $F(x_{\rm out})-F(x_\star)\le\varepsilon$, $\varepsilon>0$, almost surely, for the last complete-pass iterate. The guarantee holds for every outcome. Updates use $m,L,x_0$; stopping additionally uses $R,\varepsilon$.}\par\smallskip
