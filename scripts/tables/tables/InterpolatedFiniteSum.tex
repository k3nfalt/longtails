\parbox{\linewidth}{\footnotesize On a real Hilbert space, $m\ge1$ convex differentiable components have $L$-Lipschitz gradients and a common minimizer $x_\star$ with $\|x_0-x_\star\|\le R$; $L>0$, $R\ge0$, $\varepsilon>0$. The setup requires fixed-order cyclic gradient steps $1/L$, using exact component gradients. Its last-pass output satisfies $F(x)-F(x_\star)\le\varepsilon$ for every outcome (formally almost surely).
