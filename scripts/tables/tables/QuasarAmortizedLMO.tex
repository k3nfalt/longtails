\parbox{\linewidth}{\footnotesize On a real Hilbert space, $f$ is differentiable with globally $L$-Lipschitz gradient, $L\ge0$. The convex set $C$ contains $x_0$ and a minimizer $x_\star$, has diameter at most $D\ge0$, and satisfies $\tau(f(x)-f(x_\star))\le\langle\nabla f(x),x-x_\star\rangle$ for $x\in C$, $0<\tau\le1$. Gradients are exact. At iteration $k$, the LMO returns $s_k(v)\in C$ with $\langle v,s_k(v)\rangle\le\langle v,u\rangle+\delta_k$ for every $u\in C$, direction $v$, and oracle seed; $\delta_k\ge0$ and $\sum_{k<n}\delta_k\le\Gamma$ for every $n$, $\Gamma\ge0$. Target: feasible output with $f(x)-f(x_\star)\le\varepsilon$, $\varepsilon>0$, almost surely under the execution measure $P$. Result \textbf{(1)} constructs Frank--Wolfe with $\eta_k=2/(\tau k+2)$ and a last iterate satisfying this for every seed; the setup imposes no algorithm restriction. Updates use $\tau,x_0$; stopping uses $L,D,\tau,\Gamma,\varepsilon$.}\par\smallskip
