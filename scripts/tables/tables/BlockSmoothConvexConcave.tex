\parbox{\linewidth}{\footnotesize On real Hilbert spaces $E\times F$, $f$ is differentiable in each block and convex--concave. Partial gradients have global within-block Lipschitz bounds $L_x,L_y\ge0$ and cross-block bound $L_{xy}\ge0$, with $L_x+L_{xy},L_y+L_{xy}>0$. A saddle $z_\star$ satisfies $\|z_0-z_\star\|\le R$, where $R\ge0$. The oracle returns exact partial gradients. The setup requires constant-step Alex-GDA with $1<\gamma\le2$, $\delta\ge1$; the target is $\|\nabla_x f(\hat z)\|^2+\|\nabla_y f(\hat z)\|^2\le\varepsilon^2$, $\varepsilon>0$, deterministically.}\par\smallskip
