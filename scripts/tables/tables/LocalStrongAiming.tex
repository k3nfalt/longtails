\parbox{\linewidth}{\footnotesize Let $f:E\to\mathbb{R}$ be differentiable on a finite-dimensional real inner product space, with nonempty minimizer set $M$. For all $x,y\in U_r$, assume $\|\nabla f(x)-\nabla f(y)\|\le L\|x-y\|$ and $f(y)\ge f(x)+\langle\nabla f(x),y-x\rangle-\sqrt{\mu L}\|y-x\|^2$. For every $x\in U_r$ and every nearest $z\in M$, assume $f(x)-f_\star+\frac{\mu}{2}\|x-z\|^2\le\langle\nabla f(x),x-z\rangle$. Require $0<\mu\le L$, $r>0$, $x_0\in U_r$, and $f(x_0)-f_\star\le\Delta\le\mu r^2/256$, with $\Delta\ge0$. Exact gradients; target $f(x_K)-f_\star\le\varepsilon$, $\varepsilon>0$. Updates use $L,\mu$; the horizon additionally uses $\Delta,\varepsilon$.}\par\smallskip
