\caption{Smooth convex minimization: \href{https://github.com/k3nfalt/longtails/blob/main/LongTails/Setups/SmoothAndConvex.lean}{SmoothAndConvex}.}\label{tab:SmoothAndConvex}
\parbox{\linewidth}{\footnotesize A convex differentiable $f:E\to\mathbb R$ on a real Hilbert space has an $L$-Lipschitz gradient, $L>0$, and a minimizer $x_\star$ with $\|x_0-x_\star\|\le R$, $R\ge0$. The oracle returns the exact gradient for every query and seed. Target: $f(x_K)-f(x_\star)\le\varepsilon$, $\varepsilon>0$, almost surely under every oracle seed law. The setup imposes no algorithm restriction; the constructions use known $L$, with $R,\varepsilon$ determining the stopping budget.}\par\smallskip
