\parbox{\linewidth}{\footnotesize Differentiable $f:\mathbb{R}^{m\times n}\to\mathbb{R}$ satisfies $f\ge f_{\min}$, $f(X_0)-f_{\min}\le\Delta$, and $\|\nabla f(X)-\nabla f(Y)\|_*\le L\|X-Y\|_{\mathrm{op}}$. The jointly measurable, integrable oracle uses IID samples, with $\mathbb{E}G(X)=\nabla f(X)$ and, in a fixed orthonormal row basis $(u_i)$, $\mathbb{E}\|(G(X)-\nabla f(X))^\top u_i\|_2^2\le\sigma_i^2$, $\sigma_i\ge0$, $\sum_i\sigma_i\le s$. Here $L,\Delta,s\ge0$, $\varepsilon>0$, $0<\delta<1$. Target: $\Pr(\|\nabla f(\widehat X)\|_*>\varepsilon)\le\delta$, over sampling and algorithm randomness. The setup restricts algorithms to exact-polar EMA Muon with random candidate selection and batched robust validation (or returning $X_0$ when already certified).}\par\smallskip
