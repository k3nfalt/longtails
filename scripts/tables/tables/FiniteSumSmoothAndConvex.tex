\parbox{\linewidth}{\footnotesize On a real Hilbert space equipped with a measurable structure, $F=n^{-1}\sum_{i=1}^n f_i$, where $n\ge1$, every $f_i$ is convex with $L$-Lipschitz gradient, $L>0$, and some minimizer $x_\star$ satisfies $\|x_0-x_\star\|\le R$, $R\ge0$. One oracle call returns an exact component gradient. The target is a measurable output with integrable gap and $\int [F(\widehat x(\omega))-F(x_\star)]\,dP(\omega)\le\varepsilon$, $\varepsilon>0$, under the algorithm's randomization law $P$. The setup imposes no algorithm restriction.}\par\smallskip
