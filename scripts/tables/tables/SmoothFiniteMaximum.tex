\parbox{\linewidth}{\footnotesize In a finite-dimensional real inner-product space, minimize $F(x)=\max_{i\le m}f_i(x)$ over $B=\overline B(x_0,R)$, with $m\ge2$. Each $f_i$ is convex and differentiable on $B$, with $\|\nabla f_i\|\le G$ and $L$-Lipschitz gradient there; a constrained minimizer $x_\star\in B$ exists. Here $G,R,\varepsilon>0$, $L\ge0$, and $0<\delta<1$. One exact component query returns $(f_i(x),\nabla f_i(x))$. The target is a measurable feasible output $\widehat x$ with $\Pr\{F(\widehat x)-F(x_\star)\le\varepsilon\}\ge1-\delta$.}\par\smallskip
