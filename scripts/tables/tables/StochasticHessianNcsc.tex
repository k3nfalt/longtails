\parbox{\linewidth}{\footnotesize On finite-dimensional real inner-product spaces, $f(x,y)$ is jointly $L$-smooth, $\mu$-strongly concave in $y$, and has $\rho$-Lipschitz Hessian $\nabla^2 f$. Let $\Phi(x)=\max_y f(x,y)$, $\Phi(x_0)-\inf_x\Phi(x)\le\Delta$, and $\|\nabla_y f(x_0,y_0)\|\le G$. Here $0<\mu\le L$, $\rho,\sigma,\varepsilon>0$, and $\Delta,G\ge0$. Each call returns a jointly measurable, unbiased joint stochastic gradient with total variance at most $\sigma^2$, using a fresh IID sample. The target is $\int\|\nabla\Phi(\widehat x(\omega))\|\,d\mathbb P(\omega)\le\varepsilon$, where $\mathbb P$ includes the sampling and algorithm randomness.}\par\smallskip
