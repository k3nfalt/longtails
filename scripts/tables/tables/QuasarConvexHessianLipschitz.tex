\parbox{\linewidth}{\footnotesize On a finite-dimensional real inner-product space, $f\in C^2$ has $H$-Lipschitz Hessian and a global minimizer $x_\star$ satisfying $\gamma(f(x)-f(x_\star))\leq\langle\nabla f(x),x-x_\star\rangle$ for every $x$. Assume $H,R,\varepsilon>0$, $0<\gamma\leq1$, $\|x_0-x_\star\|\leq R$, and $\|\nabla^2 f(x_0)\|\leq L_0$ with $L_0\geq0$. Exact queries return $(f,\nabla f,\nabla^2 f)$. Result \textbf{(1)} uses known $H,\gamma,R,L_0,\varepsilon$ and constructs an accelerated cubic Newton output $\widehat x$ with deterministic accuracy $f(\widehat x)-f(x_\star)\leq\varepsilon$; the setup imposes no algorithm restriction.}\par\smallskip
