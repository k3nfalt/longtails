\parbox{\linewidth}{\footnotesize On a real Hilbert space, let $F=n^{-1}\sum_{i=0}^{n-1}f_i$, $n\ge1$, with differentiable components and exact component-gradient access. Assume $\nabla F$ is $L$-Lipschitz, each $\nabla f_i-\nabla F$ is $\delta$-Lipschitz, $0<\mu\le L$, $0<\gamma\le1$, $\delta\ge0$, and $384\delta^2\le\gamma^3\mu^2$. For a global minimizer $x_\star$, assume $F(x_0)-F(x_\star)\le\Delta$, $\Delta\ge0$, and, for all $x,y$, $F(x_\star)\ge F(x)+\gamma^{-1}\langle\nabla F(x),x_\star-x\rangle+\frac{\mu}{2}\|x-x_\star\|^2$, $F(y)\ge F(x)+\langle\nabla F(x),y-x\rangle-\frac{\gamma\sqrt{\mu L}}{2}\|y-x\|^2$, and $F(x)-F(x_\star)\ge\frac{\gamma\mu}{2(2-\gamma)}\|x-x_\star\|^2$. Target: $F(\widehat x)-F(x_\star)\le\varepsilon$, $\varepsilon>0$; \textbf{(1)} gives a deterministic final iterate. Tuning uses $L,\mu,\gamma,\delta,\Delta,\varepsilon$.}\par\smallskip
