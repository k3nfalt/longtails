\parbox{\linewidth}{\footnotesize On a finite-dimensional real inner-product space, $F:E\to E$ is monotone and satisfies $\|F(x)-F(y)\|\le L\|x-y\|+H\|x-y\|^\alpha$, with $L,H\ge0$ and $0<\alpha\le1$. A zero $x_\star$ satisfies $\|x_0-x_\star\|\le R$, and $0<r_0\le R$, $\varepsilon>0$. The exact oracle returns $F(x)$; the target is $\|F(\hat x)\|\le\varepsilon$. Result \textbf{(1)} uses only $x_0,r_0,\varepsilon$ and returns a stopped iterate deterministically; the setup imposes no algorithm restriction.}\par\smallskip
