\parbox{\linewidth}{\footnotesize On a real Hilbert space, $F=n^{-1}\sum_{i=1}^n f_i$ has differentiable components satisfying $n^{-1}\sum_i\|\nabla f_i(x)-\nabla f_i(y)\|^2\le L^2\|x-y\|^2$. There is a lower bound $\ell\le F(x)$ with $F(x_0)-\ell\le\Delta$; $n\ge1$, $L>0$, $\Delta\ge0$, $\varepsilon>0$. Queries return exact component gradients. The target is $\mathbb{E}\|\nabla F(X)\|^2\le\varepsilon^2$, with measurable output and integrable squared gradient norm. No convexity or attained minimum is assumed.}\par\smallskip
