\parbox{\linewidth}{\footnotesize Convex differentiable $f:E\to\mathbb{R}$, where $E$ is linearly isometric to $\mathbb{R}^d$, with $L$-Lipschitz gradient and a minimizer $x_\star$ satisfying $\|x_0-x_\star\|\le R$. Each value query uses a fresh IID seed $\xi\sim p$; the jointly measurable oracle satisfies $\int g(x,z)\,dp(z)=f(x)$ and $\int(g(x,z)-f(x))^2\,dp(z)\le\sigma^2$, with integrable values and squared errors. Known parameters: $d\ge1$, $L,\varepsilon>0$, $R,\sigma\ge0$. Target: measurable output $\widehat x$ with integrable gap and $\int[f(\widehat x(\omega))-f(x_\star)]\,dP(\omega)\le\varepsilon$.}\par\smallskip
