\parbox{\linewidth}{\footnotesize A continuous monotone map $F:E\to E$ on a real inner-product space satisfies
$\|F(x)-F(y)\|\le (L_0+L_1\max_{0\le t\le1}\|F(x+t(y-x))\|)\|x-y\|$.
Here $L_0>0$, $L_1,G,R\ge0$, $\varepsilon>0$, $\|F(x_0)\|\le G$, and some root $x_\star$ satisfies $\|x_0-x_\star\|\le R$. The oracle returns exact $F(x)$; the target is $\|F(x)\|\le\varepsilon$ deterministically. The setup imposes no algorithm restriction.}\par\smallskip
