\parbox{\linewidth}{\footnotesize On $\mathbb R^d$, $F=n^{-1}\sum_i f_i$ is convex, each $f_i$ is $C^2$, and $n^{-1}\sum_i\|\nabla^2f_i(x)-\nabla^2f_i(y)\|^2\le H^2\|x-y\|^2$ for all $x,y$. Some minimizer $x^\star$ satisfies $\|x^\star\|\le R$. Take $n\ge1$, $H\ge0$, $R,\varepsilon>0$, and $d\ge 2^{170}n^3(1+\lceil(S/\sqrt n)^{2/7}\rceil)^{12}$. A query $(i,x)$ returns the exact value, gradient, and full Hessian of $f_i$ at $x$. The target is $\int (F(\hat x(\omega))-F(x^\star))\,dP(\omega)\le\varepsilon$ for a measurable output with integrable gap under the run law $P$.}\par\smallskip
