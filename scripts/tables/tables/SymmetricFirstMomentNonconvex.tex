\parbox{\linewidth}{\footnotesize Differentiable $f:\mathbb{R}^d\to\mathbb{R}$ has $L$-Lipschitz gradient and $f(x_0)-f(x)\le\Delta$ for every $x$; $L,\varepsilon>0$ and $\Lambda,\sigma,\Delta\ge0$. The jointly measurable, integrable oracle $g$ uses IID samples with law $\mu$ and permits paired evaluations with the same sample. Writing $\zeta(x,\xi)=g(x,\xi)-\nabla f(x)$, assume $\mathbb{E}_{\mu}g(x,\xi)=\nabla f(x)$, $\mathbb{E}_{\mu}\|\zeta(x,\xi)\|\le\sigma$, $\mathbb{E}_{\mu}\|\zeta(x,\xi)-\zeta(y,\xi)\|\le\Lambda\|x-y\|$, and $\zeta_i(x,\xi)\overset{d}{=}-\zeta_i(x,\xi)$ for every $x,i$. Target: measurable output with $\int\|\nabla f(x_{\mathrm{out}})\|\,dP\le\varepsilon$, where $P$ is the execution law. Costs count primitive stochastic gradient evaluations, including all median samples and batches; each paired query costs two.}\par\smallskip
