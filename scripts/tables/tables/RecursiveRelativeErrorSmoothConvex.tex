\parbox{\linewidth}{\footnotesize On a real Hilbert space, $f$ is differentiable and satisfies $0\le f(y)-f(x)-\langle\nabla f(x),y-x\rangle\le L\|y-x\|^2/2$. A minimizer $x_\star$ satisfies $\|x_0-x_\star\|\le R$, with $L>0$, $R\ge0$, $\varepsilon>0$. Every oracle reply obeys $\|g-\nabla f(x)\|\le\alpha\|\nabla f(x)\|$, where $0\le\alpha\le e^{-8(1+\sqrt{\log(2+LR^2/\varepsilon)})}/100$. The target is $f(x_{\rm out})-f(x_\star)\le\varepsilon$ for every admissible reply sequence. The setup supplies $L,\alpha,R,\varepsilon,x_0$ and imposes no algorithm restriction.}\par\smallskip
