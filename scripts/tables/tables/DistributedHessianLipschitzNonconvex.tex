\parbox{\linewidth}{\footnotesize A common objective $f:\mathbb R^d\to\mathbb R$ has an $L$-Lipschitz gradient, differentiable gradient and $Q$-Lipschitz Hessian, with $f\ge f_{\rm low}$ and $f(x_0)-f_{\rm low}\le\Delta$. Here $L,\varepsilon,h_i>0$ and $Q,\Delta,\sigma,\ell,b\ge0$. The $n\ge1$ workers have jointly measurable, integrable unbiased gradient oracles of variance at most $\sigma^2$, IID samples within each worker and independent worker streams. A star network permits parallel worker computation and independent directed links, with one pending query per worker and one packet per directed link; an $m$-bit packet takes $\ell+bm$. Our constructed normalized methods return a selected coordinator iterate $X$ with $\int\|\nabla f(X(\omega))\|\,dP_{\rm exec}(\omega)\le\varepsilon$, where $P_{\rm exec}$ is the actual execution law; finite-event execution holds almost surely.
