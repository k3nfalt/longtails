\parbox{\linewidth}{\footnotesize On a real Hilbert space, $F=n^{-1}\sum_{i=1}^n f_i$, $n\ge1$, has $L$-Lipschitz gradient; each $f_i$ has a gradient. A global minimizer $x_\star$ satisfies $F(x_0)-F(x_\star)\le\Delta$ and $F(x_\star)\ge F(x)+\gamma^{-1}\langle\nabla F(x),x_\star-x\rangle+\frac\mu2\|x-x_\star\|^2$. For all $x,y$, $n^{-1}\sum_i\|[\nabla f_i-\nabla F](x)-[\nabla f_i-\nabla F](y)\|^2\le\delta^2\|x-y\|^2$. Here $0<\mu\le L$, $0<\gamma\le1$, $\delta,\Delta\ge0$, and $\varepsilon>0$. The oracle returns exact component gradients; interpolation is not required. Target: $\int [F(X(\omega))-F(x_\star)]\,dP(\omega)\le\varepsilon$, with integrable gap and $P$ the execution law. Our constructions have fixed budgets and expected final-iterate accuracy; the setup imposes no algorithm restriction.}\par\smallskip
