\parbox{\linewidth}{\footnotesize
A finite-dimensional real normed space; convex differentiable $f$ with $L$-Lipschitz derivative, $L>0$; a global minimizer $x_\star$ with $\|x_\star-x_0\|\le R$, $R\ge0$.
For $p>2$, $c>0$, the differentiable function $\psi(x)=\|x-x_0\|^2/2$ satisfies
$D_\psi(y,x)\ge c\|y-x\|^p/(\|y-x_0\|+\|x-x_0\|)^{p-2}$ for all $x,y$.
Every oracle reply obeys $\|g-Df(x)\|_*\le\alpha\|Df(x)\|_*$, $0\le\alpha\le1/4$, with arbitrary bias and call/seed dependence.
Target: $f(x_K)-f(x_\star)\le\varepsilon$, $\varepsilon>0$, for every seed, hence almost surely under any execution law. Result \textbf{(1)} constructs squared-norm dual averaging with last steepest-step output $x_K$; the setup imposes no algorithm restriction.}\par\smallskip
