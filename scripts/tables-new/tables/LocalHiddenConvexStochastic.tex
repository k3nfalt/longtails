\parbox{\linewidth}{\footnotesize In a finite-dimensional real Hilbert space, $F$ is globally $L$-smooth and has a global minimizer $x_\star$ with $\|x_0-x_\star\|\le R$. On $B(x_0,3R)$, $F=H\circ c$, with $H$ convex and differentiable on an open convex set $U$. On $\overline B(x_0,2R)$, $c(x)\in U$, $Dc(x)=J(x)$, $\|J(x)v\|\ge\mu\|v\|$, and $J$ is $L_J$-Lipschitz; $32L_JR\le\mu$. Here $L,R,\mu,\varepsilon>0$ and $L_J,\sigma\ge0$. The jointly measurable oracle $g$ has integrable values and squared errors, $\int g(x,\omega)\,dp=\nabla F(x)$ and $\int\|g(x,\omega)-\nabla F(x)\|^2\,dp\le\sigma^2$. Samples are IID with law $p$. Target: $\int[F(\widehat x)-F(x_\star)]\,dP\le\varepsilon$, where $P=p^{\otimes\mathbb N}$. The setup imposes no algorithm restriction; (1) constructs safeguarded similar triangles using $L,R,\sigma,x_0$.}\par\smallskip
