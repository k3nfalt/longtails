# Continuized variance-reduced acceleration for similar strongly quasar-convex finite sums

The [theorem](../../LongTails/Theorems/ContinuizedSimilarQuasar.lean) proves that the [continuized SVRG-type method](../../LongTails/Algorithms/ContinuizedQuasar.lean) returns a last iterate $X$ with $\mathbb E[F(X)]-F(x_\star)\le\varepsilon$ for every instance of the [setup](../../LongTails/Setups/ContinuizedSimilarQuasar.lean). Here $F=\frac1n\sum_i f_i$ on any real inner-product space, $\nabla F$ is $L$-Lipschitz, $F$ is $(\gamma,\mu)$-strongly quasar-convex about a global minimizer $x_\star$, and $F(x_0)-F_\star\le\Delta$. Similarity requires $\frac1n\sum_i\|(\nabla f_i-\nabla F)(x)-(\nabla f_i-\nabla F)(y)\|^2\le\delta^2\|x-y\|^2$. No interpolation is assumed, and component values are not used. The assumed quadratic growth already follows from strong quasar-convexity ([Hinder–Sidford–Sohoni, COLT 2020, Cor. 1](https://proceedings.mlr.press/v125/hinder20a/hinder20a.pdf)).

**Complexity.** The deterministic budget is $\lceil\log_2(1+2\Delta/(\gamma\varepsilon))\rceil$ epochs, each costing $n+\lceil 8\sqrt{L/\mu}/\gamma+4096\,\delta^2/(\gamma^3\mu^2)\rceil$ component-gradient calls:
$$O\Big(\big(n+\tfrac{\sqrt{L/\mu}}{\gamma}+\tfrac{\delta^2}{\gamma^3\mu^2}\big)\big(1+\log(1+\tfrac{\Delta}{\gamma\varepsilon})\big)\Big),$$
where $0<\mu\le L$ and $0<\gamma\le1$. Updates need $L,\mu,\gamma,\delta$, and stopping needs $\Delta,\varepsilon$. If $n=1$, then $\delta=0$.

**Reductions used below.** By Cauchy–Schwarz and AM–GM, strong quasar-convexity gives $\gamma(F-F_\star)\le\|\nabla F\|r-\tfrac{\gamma\mu}2r^2\le\|\nabla F\|^2/(2\gamma\mu)$, so $F$ is PL with constant $\gamma^2\mu$. Since $\frac1n\sum\|\nabla f_i(x)-\nabla f_i(y)\|^2=\|\nabla F(x)-\nabla F(y)\|^2+(\text{centered term})$, the mean-squared smoothness is at most $\sqrt{L^2+\delta^2}$. Each component is $(L+\sqrt n\,\delta)$-smooth.

**Reduction check and proof ancestry.** PL-based variance reduction and full-batch acceleration give the rows above, not the current bound. Interpolation-based results ([Fu et al.](https://proceedings.mlr.press/v202/fu23e/fu23e.pdf); [Hermant et al., arXiv 2512.16533v2, Assumption 4/Thm. 12](https://arxiv.org/html/2512.16533v2), which assume strong growth) do not apply because the SVRG noise $\delta^2\|x-w\|^2$ need not vanish at $x_\star$. Similarity-based accelerated variance-reduction methods for convex $F$ use proximal oracles and convexity. The case $n=1$ is essentially [Wang–Wibisono, ICLR 2023, Thm. 2/Cor. 2](https://arxiv.org/pdf/2302.07851), which proves the $\sqrt{L/\mu}/\gamma$ rate with constant probability. That paper and [Even et al., NeurIPS 2021](https://papers.nips.cc/paper/2021/file/ec26fc2eb2b75aece19c70392dc744c2-Paper.pdf) supply the continuized energy. The new step is to control the snapshot-variance term inside that energy and convert exponential holding times into a fixed-jump epoch contraction.

**Conclusion**

**Yes, the proved total complexity is better when component similarity is small, but it is worse when similarity is large.** The strongest applicable gradient-only baseline is PAGE. Strong quasar-convexity makes PAGE applicable through the PL condition.

| this result | $(n+\sqrt{L/\mu}/\gamma+\delta^2/(\gamma^3\mu^2))\log(1+\Delta/(\gamma\varepsilon))$ |

If $\delta^2\le\gamma\sqrt n\,L\mu$, the result is never worse up to constants and a $\log(1/\gamma)$ term. The speedup is $\asymp(n+\sqrt n L/(\gamma^2\mu))/(n+\sqrt{L/\mu}/\gamma)$, which is polynomial; for example, $\gamma=1$ and $n=L/\mu=\kappa$ improve $\kappa^{3/2}$ to $\kappa$. It also beats full-batch accelerated search (Hinder et al.) and uses no function values. For large similarity, such as $\delta\approx L$, PAGE and Hinder's method are better.

The comparison proves this regime-specific gain. The search found no earlier accelerated variance-reduced guarantee for non-interpolating strongly quasar-convex finite sums, but that is not proof of priority. The expectation output is weaker than Hinder's deterministic accuracy. The subsequent repository theorem on the identical setup now dominates this one except in a narrow window with a small $\gamma$-dependent gain.

The contribution that can be claimed is the first gradient-only accelerated variance-reduced rate for strongly quasar-convex finite sums without interpolation that I found, with a polynomial speedup over checked methods when $\delta$ is small relative to $\mu$. That gain fails when $\delta$ is large.
