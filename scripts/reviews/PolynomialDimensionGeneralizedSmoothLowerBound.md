# Randomized hardness for convex (L₀,L₁)-smooth minimization in polynomial dimension

[`result`](../../LongTails/Theorems/PolynomialDimensionGeneralizedSmoothLowerBound.lean) shows the following for convex (L₀,L₁)-smooth objectives on ℝᵈ that have a minimizer within distance R of x₀ ([setup](../../LongTails/Setups/GeneralizedSmoothConvexPolynomialDimension.lean), with the admissible class reused from [RadiusOnlyGeneralizedSmoothConvex](../../LongTails/Setups/RadiusOnlyGeneralizedSmoothConvex.lean)). For every randomized adaptive gradient-oracle algorithm and every budget b up to the stated budget, there is a seed-independent instance with a deterministic exact-gradient oracle on which the output fails `E[f(x̂) − f*] ≤ ε`. The algorithm is unrestricted; the [hard construction](../../LongTails/Proofs/PolynomialDimensionGeneralizedSmoothLowerBound.lean) uses a random coordinate embedding plus a finite-family averaging argument.

**Necessary budget.** Write q = L₁R. Here L₀ and L₁ are the affine curvature constants in ‖∇²f‖ ≤ L₀ + L₁‖∇f‖, R is the minimizer radius, ε is the target expected gap, and d is the dimension. Any successful method needs

  N ≥ ⌊L₁R / (4096·log(2+L₁R))⌋ + 1 = Ω(L₁R / log(2+L₁R)) gradient calls,

under the conditions L₁R ≥ 2²⁰, L₀/L₁² ≤ ε ≤ L₀R²/16, and d ≥ ⌈2⁴⁴(1+L₁R)⁵⌉. The initial gap is not bounded. The parameter regime is nonempty (`valid_nonempty`). In this regime √(L₀R²/ε) ≤ L₁R, so the classical randomized smooth lower bound Ω(√(L₀R²/ε)) is dominated. The matching upper bound is Sherpa's O(√(L₀R²/ε) + (1+L₁R)log(2+L₁R)) ([Everest I, Thm 3.7](https://arxiv.org/abs/2610.21461)). This leaves a log²(2+L₁R) gap.

**Reduction check and proof ancestry.** There is no unconditional off-the-shelf randomization: [Woodworth–Srebro (2016)](https://arxiv.org/abs/1605.08003) and [Carmon et al. (2017)](https://arxiv.org/abs/1710.11606) use random embeddings, which need a localization that hides the chain from far-away queries. The uniform-Hessian radial extension (Everest II, Lemma D.4) is required to satisfy ‖∇²H‖ ≤ L_aux with 4G/r ≤ L_aux/3. Because the chain's gradient G is of order e^{Θ(√L₁R)}, keeping L_aux ≲ L₀ forces an exponential radius and therefore exponential dimension. This is plausibly the route of commit 0ed1e4a6. The new mechanism is a compact polynomial hinge with p′ ≤ 2n(n+1)(p + 2⁻ⁿ), whose transition curvature is absorbed into L₁‖∇F‖ plus a tiny L₀ remainder ([AdaptivePolynomialHinge](../../LongTails/Proofs/AdaptivePolynomialHinge.lean), [AdaptiveGeneralizedSmoothLocalization](../../LongTails/Proofs/AdaptiveGeneralizedSmoothLocalization.lean)). I checked this mechanism only through the companion note and the lemma structure, not line by line. The chain and conjugate construction descend from Everest I; the exponential local-growth estimate is due to [Chen et al., ICML 2023](https://proceedings.mlr.press/v202/chen23ar.html).

**Conclusion**

**The rate is unchanged; what is new is extending the known L₁R hardness to randomized algorithms, in polynomial dimension.** The strongest baseline is Everest I, which proves the same hardness for deterministic methods, with a √log-stronger rate and a value-and-gradient oracle:

| | Algorithms | Lower bound on calls | Dimension |
|---|---|---|---|
| Everest I, Thm 4.10 | deterministic | L₁R/√log(2+L₁R) | O(L₁R) |
| This result | randomized | L₁R/log(2+L₁R) | 2⁴⁴(1+L₁R)⁵ |

Combined with Sherpa's O((1+L₁R)log(2+L₁R)) upper bound, the result shows that randomization cannot beat the initialization term by more than log²(L₁R), for L₀/L₁² ≤ ε ≤ L₀R²/16. Everest II already proves randomized hardness of this scale, but only for sums of at least two components and in unbounded dimension. Its uniform-curvature localization, applied to one function, appears to give only exponential dimension.

The gain is real but modest. It closes a natural gap in the algorithm class without changing the rate, loses √log, and requires a weaker oracle and much larger dimension. The essential new step is the localization that preserves gradient-dependent curvature. I did not check whether a cheaper randomization of Everest I's rotation-based argument exists, and no published priority conflict was found. What can be claimed is the first randomized, gradient-oracle lower bound Ω(L₁R/log(L₁R)) for single convex (L₀,L₁)-smooth functions in polynomial dimension; this is an extension of the algorithm class, not a new rate.
