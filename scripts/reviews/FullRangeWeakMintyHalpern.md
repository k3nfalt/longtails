# Novelty review: FullRangeWeakMintyHalpern

The theorem proves the following. Take $F$ on a finite-dimensional inner-product space with $F$ $L_1$-Lipschitz, a derivative that is $L_2$-Lipschitz, and a zero $z$ with $\|x_0-z\|\le R$ satisfying the one-point weak Minty condition $\langle F(x),x-z\rangle\ge-(\rho/2)\|F(x)\|^2$, where $\rho L_1<2$. A public selector then returns a point with $\|F(x_{\rm out})\|\le\varepsilon$ for every seed. It chooses either a value-only Halpern/half-space method or the repository's existing hybrid that uses Jacobian queries. ([theorem](../../LongTails/Theorems/FullRangeWeakMintyHalpern.lean), [setup](../../LongTails/Setups/WeakMintySecondOrder.lean), [algorithm](../../LongTails/Algorithms/FullRangeWeakMintyHalpern.lean))

**Complexity.** Write $\delta=1-\rho L_1/2\in(0,1]$ for the margin to the boundary of the weak Minty range. Each value or Jacobian query counts as one call. Substituting $m=2\lceil2+32/\sqrt\delta\rceil+3=\Theta(\delta^{-1/2})$ into the Lean budget gives
$$
N=\begin{cases}O\!\big(\delta^{-1/2}+L_1^2R^2/(\delta\varepsilon^2)\big)\ \text{(values only)}, & \varepsilon\gtrsim L_1^2\delta^4/(L_2\log(2/\delta)),\\[2pt] O\!\big((1+L_2R^2/\varepsilon)\,\delta^{-5}\log(2/\delta)\big), & \text{otherwise.}\end{cases}
$$
The case test is the exact public comparison $c_v\le c_h$. It is independent of $R$.

**Reduction and mechanism check.** The obvious reduction does not reach $\delta^{-1}$. Project onto the shifted half-space at an (inexact) resolvent $y=J_{\gamma F}(w)$ with $\gamma<1/L_1$. This gives a depth of only $(\gamma-\rho/2)\|F(y)\|\le(\delta/L_1)\|F(y)\|$, hence $\Theta(T_1/\delta^2)$ outer steps plus inner cost, which is the PMC/AKW structure. The new step is the two-center construction. It solves $u=c-G(u)$ by Halpern at $\gamma=1/L_1$ with $K\asymp\delta^{-1/2}$ (Lieder's displacement bound). It then uses Lipschitz inequalities from both the anchor and the first endpoint to get depth $\ge\delta^{1/4}\|F(w)\|/(16L_1)$. That makes $O(T_1/\sqrt\delta)$ outer steps of $O(\delta^{-1/2})$ values each. I found no prior instance of this mechanism. Proof ancestry: Halpern 1967 and Lieder 2021 (inner residual), Solodov–Svaiter 1999 and PMC 2025 (shifted half-space projection). None of them supplies the $\delta$-rate. Alacaoglu–Kim–Wright ([ICML 2024](https://arxiv.org/abs/2402.05071), Thm 3.1/Cor 3.2) give $\widetilde O(T_1/\delta^3)$ (my derivation, with $\eta=(\rho/2+1/L_1)/2$) for a non-computable resolvent residual, so it is not a stronger row.

## Conclusion

**Yes: near the edge of the weak Minty range, the proved value-only complexity is two powers of the margin better than the best prior first-order bound I could find.**

The strongest checked baselines are Böhm's OGDA+ (retuned Thm A.1) and Pethick–Mavrothalassitis–Cevher's corrected inexact proximal point method (ICLR 2025). Both cover the full range $\rho L_1<2$ with value queries only:

| | value calls to $\|F\|\le\varepsilon$ |
|---|---|
| Böhm / PMC | $O(1+L_1^2R^2/(\delta^3\varepsilon^2))$ / $O(\delta^{-1}\log\tfrac3\delta\,(1+L_1^2R^2/(\delta^2\varepsilon^2)))$ |
| This result (when $\varepsilon\gtrsim L_1^2\delta^4/(L_2\log(2/\delta))$) | $O(\delta^{-1/2}+L_1^2R^2/(\delta\varepsilon^2))$ |

In that $\varepsilon$ range, the gain over Böhm survives whenever $L_1^2R^2/\varepsilon^2\gg\delta^{5/2}$, and the bound is never worse than PMC up to constants. Below that range, the theorem falls back to the old Jacobian hybrid. Its $\delta^{-5}\log(2/\delta)$ intercept can exceed Böhm's bound unless $L_1^2R^2/\varepsilon^2\gtrsim\delta^{-2}\log(2/\delta)$. The theorem's class is narrower than the baselines': it requires an $L_2$-Lipschitz Jacobian, which the value branch never uses beyond the selector. PMC also handles constraints.

The comparison proves the gain over these baselines. The search only supports priority: it does not prove it, and the optimal margin dependence remains unknown. What can be claimed is a new value-only, full-range weak Minty method whose two-center Halpern/half-space step improves the margin dependence from $\delta^{-3}$ to $\delta^{-1}$.
