# Novelty assessment: QuasarAcceleratedCubicNewton

The theorem ([theorem](../../LongTails/Theorems/QuasarAcceleratedCubicNewton.lean), [setup](../../LongTails/Setups/QuasarConvexHessianLipschitz.lean), [algorithm](../../LongTails/Algorithms/QuasarCubicNewton.lean)) covers C² functions f on a finite-dimensional space whose Hessian is H-Lipschitz and which are γ-quasar-convex with respect to a global minimizer x⋆, with ‖x₀ − x⋆‖ ≤ R. The algorithm receives (f, ∇f, ∇²f) at each query and knows H, γ, R, L₀ and ε. It proves deterministically that the last outer iterate x̂ of an accelerated cubic Newton method satisfies f(x̂) − f(x⋆) ≤ ε.

**Proved oracle complexity.** Each call returns one (f, ∇f, ∇²f) triple. The parameters are H (Hessian-Lipschitz constant), γ ∈ (0,1] (quasar parameter), R (initial distance) and L₀ ≥ ‖∇²f(x₀)‖. The budget `K·(depth+1)+1` simplifies to

  N = O( (1 + γ^{-3/2}(HR³/ε)^{3/8}) · log(2 + HR³/ε + L₀/(HR) + 1/γ) ).

The setup requires no global gradient-Lipschitz constant, no convexity, no bounded sublevel sets and no ‖∇f(x₀)‖.

**Reductions and mechanism.** I found no standard reduction that yields the ε^{-3/8} rate. Regularization destroys quasar-convexity. Converting a stationarity bound into a gap bound needs a distance bound and gives NP's ε^{-1/2}. Plugging a local L into HSS needs control of the iterates, which no checked result provides. The proof ancestry is Nesterov's (2008) cubic estimate sequence and HSS's segment search for the quasar coupling. The apparent new step is bisecting on the cubic model envelope f(y) + min_h m_y(h), which certifies an approximate coupling at the stepped point. It also bounds ‖v_k − x⋆‖ internally, which removes D. Its relative error H/M is why the exponent stops at 3/8, and whether ε^{-1/3} is reachable remains open. The best applicable lower bound is the convex second-order bound Ω((HR³/ε)^{2/7}); I found none specific to quasar-convex functions.

**Search coverage.** I searched on 2026-11-06 (UTC): arXiv and the web for quasar-, star- and weakly-quasi-convex second-order and tensor methods, including [HiPPA 2604.26735](https://arxiv.org/abs/2604.26735) (exact high-order prox, not accelerated, Hessian-free), [Guminov–Gasnikov–Kuruzov 1710.00797](https://arxiv.org/abs/1710.00797) (first-order only), [OPTAMI 2410.04083](https://arxiv.org/abs/2410.04083) (acceleration only under convexity) and [Kamzolov et al. 2302.04987](https://arxiv.org/abs/2302.04987) (non-accelerated for star-convex functions). I read the theorem statements of NP and HSS, but not every appendix. I did not check conference proceedings exhaustively. The result entered the repository in commit 8bb933ac (2026-11-06). The companion note has two discrepancies. Its GLM instance has bounded φ″, so it is globally L-smooth and HSS applies to it; it therefore does not show the "no global L" scope. Also, its crossover estimate of ~10^{30} is optimistic; my estimate is ~10^{37}. I did not run the build or the axiom audit.

## Conclusion

**Yes: for second-order methods on this class, the proved rate is better than any guarantee I found.** The strongest applicable published baseline is Nesterov–Polyak cubic Newton. It is stated for γ = 1, and its γ < 1 extension is only a reconstruction.

| | Calls for f(x̂) − f⋆ ≤ ε |
|---|---|
| Cubic Newton (needs bounded level set, diameter D) | O(1 + γ^{-3/2}(HD³/ε)^{1/2}) |
| This result (only ‖x₀ − x⋆‖ ≤ R) | O((1 + γ^{-3/2}(HR³/ε)^{3/8}) log(2 + HR³/ε + L₀/(HR) + 1/γ)) |

The gain is a factor (HR³/ε)^{1/8} up to logarithms. It also removes the bounded-level-set requirement. With the proved constants, it shows only when HR³/ε is above about 10^{37} (for D ≈ R). The result loses to accelerated methods on convex functions (ε^{-1/3}, optimal ε^{-2/7}). In fixed dimension it loses to Lee–Valiant's dimension-dependent zeroth-order method, which has a weaker output criterion. Against first-order acceleration (HSS) it is not comparable, though it covers nonconvex instances with cubic growth that have no global gradient-Lipschitz constant.

The comparison establishes the exponent gain over the cubic Newton baseline. Priority rests only on a search that found no accelerated Hessian-oracle guarantee for quasar- or star-convex functions; it is not proof that none exists. The claimable contribution is the first partial acceleration ε^{-1/2} → ε^{-3/8} for second-order methods on Hessian-Lipschitz quasar-convex functions, using a model-envelope coupling search. The γ-dependence is not improved, and the gap to ε^{-1/3} is open.

**Verdict: SUBSTANTIVE NOVELTY SUPPORTED**
**Confidence: medium**
