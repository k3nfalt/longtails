# A lower bound for stationarity with corrupted first-order replies

Let $T=LΔ/ε²$. For every randomized algorithm and every budget $N≤k+⌊T/2^{25}⌋$, there is a smooth objective and an admissible oracle for which the returned point has gradient norm greater than $ε$ with outer probability greater than $1/4$. The hard instance may depend on the algorithm and budget. It is fixed before the algorithm draws its seed. The guarantee covers $N=0$ and the stated budget itself. ## Model and regime

The algorithm can query any point in Euclidean space and receives a value and a full gradient vector together. The objective has $L$-Lipschitz gradient and initial value at most $Δ$ above a global lower bound. The model allows any $k$ replies to be corrupted, and accommodates bounded clean value error and a fixed approximate clean gradient map. The hard oracle uses exact clean values and gradients. Charging one call per pair gives the same information and cost model as the paired upper bound. Both results allow any prescribed failure probability between zero and $1/4$.

The lower bound requires $T≥2^{26}$ and $d≥2^{32}(1+⌊T/2^{25}⌋)^4$. Both conditions are independent of $k$. For example, $L=2^{26}$ and $Δ=ε=1$ permit every $k$ in dimension $2^{32}·3^4$ and above. The upper bound applies in every dimension. At small gaps the initial point itself can be stationary to the requested tolerance, so the lower-bound regime matters. The pair closes the query complexity to universal factors in the displayed high-dimensional regime. The constants are large, and the proof leaves the optimal dimension threshold unresolved. ## Why both costs survive unrestricted queries

The first $m=\min(N,k)$ replies are zero pairs. After these replies the algorithm has a seed-dependent state that contains no information about the hidden objective. The remaining $n=N-m$ replies use a smooth nonlinear chain of length $n+1$ embedded in a hidden ordered subset of the coordinates. A radial wall prevents unrestricted large queries from disclosing the hidden coordinates. The objective is translated to the public starting point and scaled so that an undisclosed final coordinate implies a gradient norm of at least $3ε$. [Chain simulation](../Proofs/CorruptedFirstOrderChain.lean) · [Delayed oracle and execution](../Proofs/CorruptedFirstOrderDelay.lean)

For each fixed seed the simulation reveals at most one new coordinate per call unless the algorithm guesses a sufficiently large hidden coordinate. The simulation includes the function value, and counts the returned point as a further opportunity to guess. Under the dimension condition at most one eighth of the ordered embeddings yield such a guess. Averaging across embeddings gives a single objective with failure probability greater than one quarter. The proof uses measurable supersets of the failure events, so the outer-probability statement covers every algorithm admitted by the template. ## Contribution relative to clean lower bounds

Carmon, Duchi, Hinder and Sidford established the randomized clean lower bound of order $T$ in Theorem 2 for first-order smoothness. For measurable randomized methods their construction needs dimension of order $T^2\log(2T)$ at fixed confidence. Prefixing the uninformative replies preserves that dimension: after the prefix, simulate the proposed algorithm using the clean oracle and include its returned point as one additional query. Our finite-coordinate proof needs quartic dimension and also covers arbitrary template maps through outer probability. The finite hidden-coordinate argument here reuses the repository's smooth chain and embeds it after the adversary's initial delay. The delay is elementary. Its role is to establish the matching converse for the same joint oracle, output criterion, and unrestricted algorithm class as the new upper bound. The substantive algorithmic gain in the pair is that every additional arbitrary faulty reply costs only a constant amortized number of calls despite the possibility of unbounded false values and gradients. It uses known $k$ and trusted optimizer state. [Carmon et al., Theorem 2](https://arxiv.org/abs/1710.11606) · [Descent algorithm](../Algorithms/CorruptedFirstOrderDescent.lean)
