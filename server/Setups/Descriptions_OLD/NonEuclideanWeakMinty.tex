\section*{Non-Euclidean Weak Minty Root Finding}
We consider finding a zero of an operator $F:E\to E^*$ on a finite-dimensional real normed space $E$, where $E^*$ is its continuous dual. The operator is Lipschitz and satisfies a weak Minty inequality relative to a zero $x^\star$. A differentiable strongly convex function $h:E\to\mathbb{R}$ defines the Bregman distance from a given initial point $x^0\in E$ to this zero, with a prescribed bound. Each oracle call at $x\in E$ returns the exact dual vector $F(x)$. For an accuracy level $\varepsilon>0$, the required output $\bar{x}\in E$ satisfies $\|F(\bar{x})\|_*\leq\varepsilon$ almost surely, where $\|\cdot\|_*$ is the dual norm.

The root-finding problem is
\[
\text{find }x\in E\text{ such that }F(x)=0.
\]
Write $\|\cdot\|$ for the norm on $E$ and $\langle v,z\rangle=v(z)$ for the pairing of $v\in E^*$ with $z\in E$. The public data are $(E,L,\rho,\mu,h,x^0)$, with parameter ranges
\[
L>0,\qquad 0\leq\rho\leq\frac{1}{20L},\qquad \mu>0.
\]
The remaining parameters are an initial Bregman bound $D\geq0$ and the accuracy level $\varepsilon>0$. The geometry, operator, and oracle satisfy the following conditions.

\begin{assumption}[Bregman geometry]
The function $h$ is Fr\'echet differentiable at every point of $E$. Its Bregman divergence is
\[
B_h(u,x)=h(u)-h(x)-\langle Dh(x),u-x\rangle,
\]
where $Dh(x)\in E^*$ is its derivative, and it satisfies
\[
B_h(u,x)\geq\frac{\mu}{2}\|u-x\|^2
\qquad\text{for all }x,u\in E.
\]
\end{assumption}

\begin{assumption}[Lipschitz operator]
For every $x,y\in E$,
\[
\|F(x)-F(y)\|_*\leq L\|x-y\|.
\]
\end{assumption}

\begin{assumption}[Weak Minty condition and initialization]
There exists $x^\star\in E$ such that
\[
\begin{aligned}
F(x^\star)&=0,\\
B_h(x^\star,x^0)&\leq D,\\
\langle F(x),x-x^\star\rangle&\geq-\rho\|F(x)\|_*^2
\qquad\text{for every }x\in E.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Exact operator access]
Oracle ID $0$ returns $F(x)\in E^*$ at every query point $x\in E$, at every call index, and for every realization of its randomness. Each query costs one oracle call. Any internal algorithm randomness is independent of the oracle randomness.
\end{assumption}

The operator is accessed through this oracle, with adaptive queries permitted anywhere in $E$. The algorithm is selected using only the public data $(E,L,\rho,\mu,h,x^0)$; neither $D$ nor $\varepsilon$ is supplied to it. An externally specified call budget $K\in\mathbb{N}$ may depend on the full parameter tuple $(E,L,\rho,\mu,h,x^0,D,\varepsilon)$.

After at most $K$ oracle calls, the algorithm returns $\bar{x}\in E$. Writing $\mathbb{P}$ for the joint law of the independent algorithm and oracle randomness, the accuracy requirement is
\[
\|F(\bar{x})\|_*\leq\varepsilon
\qquad\mathbb{P}\text{-almost surely}.
\]
