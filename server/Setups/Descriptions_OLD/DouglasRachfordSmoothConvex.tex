\section*{Smooth Convex Splitting with Proximal Access}
We consider minimizing $f+g$ over a convex set $C$ in a real Hilbert space $E$, where $f,g:E\to\mathbb{R}$, $f$ is differentiable and convex with hidden smoothness bound $L>0$, and $g$ is convex on $C$. Public inputs are $E$, a proximal parameter $\gamma>0$, a relaxation parameter $\lambda\in(0,1]$, and an initial point $x^0\in E$. Some minimizer $x^\star\in C$ satisfies $\|x^0-(x^\star+\gamma\nabla f(x^\star))\|\leq R$ for a hidden bound $R>0$. Each oracle call returns an exact proximal minimizer for either $f$ on $E$ or $g$ on $C$, using $\gamma$. For $\varepsilon>0$, success requires a feasible output $\bar{x}\in C$ with $f(\bar{x})+g(\bar{x})-f(x^\star)-g(x^\star)\leq\varepsilon$ almost surely.

The optimization problem is
\[
\min_{x\in C}\bigl(f(x)+g(x)\bigr).
\]
The space $E$ is complete, with norm induced by its real inner product, and may be infinite dimensional. The parameters satisfy
\[
L>0,\qquad \gamma>0,\qquad 0<\lambda\leq 1,
\qquad 4\gamma L\leq\lambda,\qquad R>0,\qquad\varepsilon>0.
\]
The admissible instances and oracle access satisfy the following conditions.

\begin{assumption}[Smooth convex component]
The function $f$ is differentiable everywhere on $E$, with gradient $\nabla f(x)$ at each $x\in E$. For every $x,y\in E$,
\[
\begin{aligned}
f(x)+\langle\nabla f(x),y-x\rangle
&\leq f(y),\\
f(y)&\leq f(x)+\langle\nabla f(x),y-x\rangle
+\frac{L}{2}\|y-x\|^2.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Convex feasible component]
The set $C\subseteq E$ is convex. For every $x,y\in C$ and $t\in[0,1]$,
\[
g((1-t)x+ty)\leq (1-t)g(x)+tg(y).
\]
\end{assumption}

\begin{assumption}[Attainment and shifted initial distance]
There exists $x^\star\in C$ such that
\[
\begin{aligned}
f(x^\star)+g(x^\star)&\leq f(x)+g(x)
\qquad\text{for every }x\in C,\\
\|x^0-(x^\star+\gamma\nabla f(x^\star))\|&\leq R.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Exact proximal access]
At every call index and for every realization of the oracle randomness, a query of the first type at $w\in E$ returns a point $u\in E$ satisfying
\[
u\in\operatorname*{arg\,min}_{x\in E}
\left\{f(x)+\frac{\|x-w\|^2}{2\gamma}\right\}.
\]
A query of the second type at $v\in E$ returns a point $z\in C$ satisfying
\[
z\in\operatorname*{arg\,min}_{y\in C}
\left\{g(y)+\frac{\|y-v\|^2}{2\gamma}\right\}.
\]
Each query of either type costs one oracle call. Any internal algorithm randomness is independent of the oracle randomness.
\end{assumption}

Queries of either type may be chosen adaptively anywhere in $E$, including outside $C$. The algorithm is selected using only the public inputs $(E,\gamma,\lambda,x^0)$; $L$, $R$, and $\varepsilon$ are not supplied to it. An externally specified call budget $K\in\mathbb{N}$ may depend on the full parameter tuple $(E,\gamma,\lambda,x^0,L,R,\varepsilon)$ and counts both types of proximal query.

After $K$ calls, the algorithm returns $\bar{x}\in E$. Writing $\mathbb{P}$ for the joint law of the algorithm and oracle randomness, success requires a minimizer $x^\star\in C$ for which
\[
\begin{aligned}
\bar{x}&\in C,\\
f(\bar{x})+g(\bar{x})-f(x^\star)-g(x^\star)&\leq\varepsilon
\end{aligned}
\qquad\mathbb{P}\text{-almost surely}.
\]
All minimizers over $C$ have the same objective value, so the minimizer witnessing the shifted initial distance bound may also be used in this accuracy criterion.
