\section*{Known-Value Local Linear Optimization}
We consider minimizing $f:E\to\mathbb{R}$ over a closed convex set $C$ in a real Hilbert space $E$. On $C$, the objective is differentiable and satisfies convex first-order and quadratic upper bounds with known constant $L>0$. A given point $x^0\in C$ is within distance $R\geq0$ of a minimizer $x^\star$ with known value $f^\star=f(x^\star)$. The oracle returns either an exact value and gradient or a linear minimizer over a ball intersected with $C$. For $\varepsilon>0$, the output $\bar{x}$ must lie in $C$ and satisfy $f(\bar{x})-f^\star\leq\varepsilon$ almost surely.

The optimization problem is
\[
\min_{x\in C} f(x).
\]
The space $E$ is complete, with inner product $\langle\cdot,\cdot\rangle$ and induced norm $\|\cdot\|$. The public inputs are $(E,L,R,\varepsilon,f^\star,x^0)$, where $f^\star\in\mathbb{R}$; the objective $f$ and feasible set $C$ are accessed through the oracle described below.

\begin{assumption}[Feasible set]
The set $C\subseteq E$ is closed and convex, and $x^0\in C$.
\end{assumption}

\begin{assumption}[Convex first-order and smoothness bounds]
The function $f$ is differentiable at every $x\in C$, with gradient $\nabla f(x)\in E$. For every $x,y\in C$,
\begin{align*}
f(y) &\geq f(x)+\langle\nabla f(x),y-x\rangle,\\
f(y) &\leq f(x)+\langle\nabla f(x),y-x\rangle
       +\frac{L}{2}\|y-x\|^2.
\end{align*}
\end{assumption}

\begin{assumption}[Known optimum and initial distance]
There exists $x^\star\in C$ such that
\begin{align*}
f(x^\star) &\leq f(x) \qquad \text{for every }x\in C,\\
f(x^\star) &= f^\star,\\
\|x^0-x^\star\| &\leq R.
\end{align*}
\end{assumption}

\begin{assumption}[Exact value-gradient and local linear access]
A single oracle, with ID $0$, accepts two types of queries. A value-gradient query at $x\in C$ returns
\[
\bigl(f(x),\nabla f(x)\bigr).
\]
A local linear query $(x,r,g)$, with $x\in C$, $r\geq0$, and $g\in E$, returns a point $v$ satisfying
\begin{align*}
v&\in C, \qquad \|v-x\|\leq r,\\
\langle g,v\rangle&\leq\langle g,z\rangle
\quad\text{for every }z\in C\text{ with }\|z-x\|\leq r.
\end{align*}
These guarantees hold at every call index and for every realization of oracle randomness. Either query costs one call to oracle $0$. Any algorithm randomness is independent of oracle randomness.
\end{assumption}

An algorithm may use the public inputs and oracle replies to choose queries and produce a point $\bar{x}\in E$. The setup does not prescribe an update family or output-selection rule. An external budget $N\in\mathbb{N}$ limits the total number of calls to oracle $0$ and may depend on the public inputs. Both query types, including unsuccessful local radius trials, count toward this budget. Queries with centers outside $C$ carry no oracle guarantee.

Writing $\mathbb{P}$ for the joint law of algorithm and oracle randomness, success requires a minimizer $x^\star\in C$ with $f(x^\star)=f^\star$ such that
\[
\bar{x}\in C,
\qquad f(\bar{x})-f(x^\star)\leq\varepsilon
\qquad \mathbb{P}\text{-almost surely}.
\]
