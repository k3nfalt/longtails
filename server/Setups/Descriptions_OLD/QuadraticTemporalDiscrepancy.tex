\section*{Quadratic Optimization with Temporal Discrepancy}
We consider minimizing $f(x)=\|A(x-x^\star)\|^2/2$ on a real Hilbert space $E$, where $A:E\to E$ is bounded and linear and $x^\star\in E$. For constants $0<\mu\leq L$, assume $\mu\|v\|^2\leq\|Av\|^2\leq L\|v\|^2$ for every $v\in E$. The initial point $x^0\in E$ satisfies $f(x^0)\leq\Delta$, where $\Delta\geq0$. Call $k$ at $x\in E$ returns $\nabla f(x)+e_k$, where $(e_k)_{k\geq0}\subset E$ is deterministic and every prefix sum has norm at most $D\geq0$. Given $\varepsilon>0$, the required output $\bar{x}\in E$ satisfies $f(\bar{x})-f(x^\star)\leq\varepsilon$ almost surely. Only $(E,L,x^0,\mu)$ are public algorithm inputs.

The optimization problem is
\[
\min_{x\in E} f(x),
\]
where $E$ may be infinite dimensional and its norm is induced by its inner product. The objective and oracle satisfy the following conditions.

\begin{assumption}[Quadratic structure and spectral bounds]
The instance consists of a bounded linear operator $A:E\to E$ and a point $x^\star\in E$. Writing $A^*$ for the Hilbert space adjoint, the objective and its gradient are
\[
\begin{aligned}
f(x)&=\frac12\|A(x-x^\star)\|^2,\\
\nabla f(x)&=A^*A(x-x^\star).
\end{aligned}
\]
The parameters satisfy $0<\mu\leq L$, and, for every $v\in E$,
\[
\mu\|v\|^2\leq\|Av\|^2\leq L\|v\|^2.
\]
Thus $f$ is $\mu$-strongly convex with $L$-Lipschitz gradient, and $x^\star$ is its unique minimizer with $f(x^\star)=0$.
\end{assumption}

\begin{assumption}[Initial objective bound]
The initial point $x^0\in E$ and the parameter $\Delta\geq0$ satisfy
\[
f(x^0)\leq\Delta.
\]
\end{assumption}

\begin{assumption}[Bounded temporal discrepancy]
For a parameter $D\geq0$, there exists a fixed deterministic sequence $(e_k)_{k\geq0}\subset E$ such that, at every call index $k\geq0$ and every query $x\in E$, the oracle returns
\[
g_k(x)=A^*A(x-x^\star)+e_k
\]
for every realization of its randomness. The same sequence applies to all query points and satisfies
\[
\left\|\sum_{k=0}^{n-1}e_k\right\|\leq D
\qquad\text{for every integer }n\geq0,
\]
with the empty sum equal to zero. Each query returns one vector in $E$ and costs one oracle call. Any internal algorithm randomness is independent of the oracle randomness.
\end{assumption}

Queries may be chosen adaptively anywhere in $E$. The algorithm is selected using only $(E,L,x^0,\mu)$; the operator $A$, minimizer $x^\star$, and error sequence are accessed only through the oracle. The parameters $D$, $\Delta$, and $\varepsilon>0$ are not supplied to the algorithm. An externally specified call budget $K\in\mathbb{N}$ may depend on the full parameter tuple $(E,L,x^0,\mu,D,\Delta,\varepsilon)$.

After $K$ calls, the algorithm returns $\bar{x}\in E$. Writing $\mathbb{P}$ for the joint law of the algorithm and oracle randomness, success requires
\[
f(\bar{x})-f(x^\star)
=\frac12\|A(\bar{x}-x^\star)\|^2
\leq\varepsilon
\qquad\mathbb{P}\text{-almost surely}.
\]
