\section*{Smooth Polyak--Lojasiewicz Exact-Gradient Optimization}
We consider minimizing a differentiable, possibly nonconvex function $f:E\to\mathbb{R}$ on a real Hilbert space $E$. Its gradient is $L$-Lipschitz, and a global minimizer $x^\star$ satisfies the Polyak--Lojasiewicz inequality $2\mu(f(x)-f(x^\star))\leq\|\nabla f(x)\|^2$ for every $x\in E$, where $0<\mu\leq L$. The initial point $x^0\in E$ satisfies $f(x^0)-f(x^\star)\leq\Delta$, where $\Delta\geq0$. Each oracle call returns the exact gradient at its query. For $\varepsilon>0$, the required output $\bar{x}\in E$ satisfies $f(\bar{x})-f(x^\star)\leq\varepsilon$ almost surely. Only $E$, $L$, and $x^0$ are public algorithm inputs.

The optimization problem is
\begin{equation}
\label{eq:problem}
\min_{x\in E} f(x),
\end{equation}
where $E$ may be infinite dimensional and its norm is induced by its inner product. The admissible objectives and oracle access satisfy the following conditions.

\begin{assumption}[Smoothness]
The function $f$ is differentiable everywhere on $E$, and its gradient satisfies
\begin{equation}
\|\nabla f(x)-\nabla f(y)\|\leq L\|x-y\|
\qquad\text{for every }x,y\in E.
\end{equation}
\end{assumption}

\begin{assumption}[Attainment and initial gap]
There exists $x^\star\in E$ such that
\begin{align}
f(x^\star)&\leq f(x) \qquad\text{for every }x\in E,\\
f(x^0)-f(x^\star)&\leq\Delta.
\end{align}
\end{assumption}

\begin{assumption}[Polyak--Lojasiewicz inequality]
Relative to this minimizer, the objective satisfies
\begin{equation}
2\mu\bigl(f(x)-f(x^\star)\bigr)\leq\|\nabla f(x)\|^2
\qquad\text{for every }x\in E.
\end{equation}
\end{assumption}

\begin{assumption}[Exact-gradient access]
At every call index and every query point $x\in E$, the oracle returns $\nabla f(x)\in E$ for every realization of its randomness. Each such query costs one oracle call. Any internal algorithm randomness is independent of the oracle randomness.
\end{assumption}

The objective is accessed through this oracle, with queries chosen adaptively anywhere in $E$. The algorithm is selected using only the public inputs $(E,L,x^0)$; the parameters $\mu$, $\Delta$, and $\varepsilon$ are not supplied to it. An externally specified call budget $K\in\mathbb{N}$ may depend on the full parameter tuple $(E,L,x^0,\mu,\Delta,\varepsilon)$.

After $K$ calls, the algorithm returns a point $\bar{x}\in E$. Writing $\mathbb{P}$ for the joint law of the algorithm and oracle randomness, success requires a global minimizer $x^\star$ for which
\begin{equation}
\label{eq:accuracy}
f(\bar{x})-f(x^\star)\leq\varepsilon
\qquad\mathbb{P}\text{-almost surely}.
\end{equation}
All global minimizers have the same objective value, so the minimizer witnessing the initial gap bound may also be used in \eqref{eq:accuracy}.
