\section*{Affine-Variance Stochastic Stationarity}
We consider finding a stationary point of a differentiable, possibly nonconvex function $f:E\to\mathbb{R}$ on a separable real Hilbert space $E$. The gradient is Lipschitz, and a given initial point has bounded objective gap above a global lower bound. Stochastic gradients are unbiased, have variance bounded by an affine function of the squared gradient norm, and satisfy mean-squared Lipschitz continuity. Each oracle call returns stochastic gradients at two queried points using one shared sample; samples are independent across calls. For $\varepsilon>0$, success requires a measurable output $\bar{x}\in E$ with integrable gradient norm and $\mathbb{E}\|\nabla f(\bar{x})\|\leq\varepsilon$, where expectation includes oracle and algorithm randomness.

The underlying optimization problem is
\[
\inf_{x\in E} f(x),
\]
where the norm on $E$ is induced by its inner product, and $E$ carries its Borel sigma-algebra. The public inputs are $E$, a measurable sample space $\Omega$, an initial point $x^0\in E$, and parameters
\[
L>0,\qquad \bar{L},\Gamma,\Lambda,\Delta\geq 0,
\qquad \varepsilon>0.
\]
The objective and its stochastic oracle satisfy the following conditions.

\begin{assumption}[Smoothness and initial gap]
The function $f$ has gradient $\nabla f(x)$ at every $x\in E$. For every $x,y\in E$,
\[
\begin{aligned}
\|\nabla f(x)-\nabla f(y)\| &\leq L\|x-y\|,\\
f(x^0)-f(x) &\leq \Delta.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Paired oracle and independent sampling]
There exist a probability measure $p$ on $\Omega$, a jointly measurable map $g:E\times\Omega\to E$, and a probability measure $P$ on $\Omega^{\mathbb{N}}$. Under $P$, the coordinate samples $(\xi_k)_{k\geq 0}$ are measurable and mutually independent, with marginal laws
\[
P\circ\xi_k^{-1}=p\qquad\text{for every }k\geq 0.
\]
At call $k$, the sole oracle, with ID $0$, accepts any pair $(x,y)\in E\times E$ and returns
\[
\bigl(g(x,\xi_k),g(y,\xi_k)\bigr)\in E\times E.
\]
This paired reply costs one oracle call. Queries may be adaptive, and any internal algorithm randomness is independent of the entire sample sequence.
\end{assumption}

\begin{assumption}[Unbiasedness and affine variance]
For every $x\in E$, the map $g(x,\cdot)$ is Bochner integrable under $p$, the function $\omega\mapsto\|g(x,\omega)-\nabla f(x)\|^2$ is integrable under $p$, and
\[
\begin{aligned}
\int_{\Omega} g(x,\omega)\,dp(\omega)
&=\nabla f(x),\\
\int_{\Omega}\|g(x,\omega)-\nabla f(x)\|^2\,dp(\omega)
&\leq \Gamma^2\|\nabla f(x)\|^2+\Lambda^2.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Mean-squared smoothness]
For every $x,y\in E$, the function $\omega\mapsto\|g(x,\omega)-g(y,\omega)\|^2$ is integrable under $p$, and
\[
\int_{\Omega}\|g(x,\omega)-g(y,\omega)\|^2\,dp(\omega)
\leq \bar{L}^2\|x-y\|^2.
\]
The two evaluations in this condition use the same sample.
\end{assumption}

The algorithm accesses the objective through the paired oracle and is selected using only the public inputs $(E,\Omega,L,\bar{L},\Gamma,\Lambda,\Delta,\varepsilon,x^0)$. The function $f$, stochastic gradient map $g$, and laws $p$ and $P$ are specified through the oracle model rather than supplied as public inputs. A call budget $K\in\mathbb{N}$ may depend on the public parameters and counts paired replies.

Within this budget, the algorithm must return a measurable point $\bar{x}\in E$. Let $\mathbb{P}$ denote the joint law of the independent algorithm randomness and sample sequence. The output must have integrable gradient norm under $\mathbb{P}$ and satisfy
\[
\int \|\nabla f(\bar{x}(\omega))\|\,d\mathbb{P}(\omega)
\leq \varepsilon.
\]
