\section*{Zeroth-Order Optimization with Affine Drift}
We consider minimizing a differentiable, possibly nonconvex function $f:\mathbb{R}^d\to\mathbb{R}$ in Euclidean space, where $d\geq1$. Its gradient is $L$-Lipschitz, and it satisfies the Polyak--{\L}ojasiewicz inequality with constant $\mu>0$ relative to a global minimizer $x^\star$. The initial point $x^0\in\mathbb{R}^d$ has bounded objective gap. Each oracle call returns a scalar function value corrupted by arbitrary affine drift within consecutive blocks of $d+2$ calls and uniformly bounded error. For a prescribed tolerance $\varepsilon>0$, the output $\bar{x}\in\mathbb{R}^d$ must satisfy $f(\bar{x})-f(x^\star)\leq\varepsilon$ almost surely.

The optimization problem is
\[
\min_{x\in\mathbb{R}^d} f(x),
\]
with the Euclidean norm denoted by $\|\cdot\|$. The public inputs are $(d,L,\mu,\varepsilon,x^0)$. The initial-gap bound $\Delta$ and oracle-error bound $\nu$ are not supplied to the algorithm. The parameters obey
\[
\begin{aligned}
&d\in\mathbb{N},\qquad d\geq1,\qquad 0<\mu\leq L,\\
&\Delta\geq0,\qquad \nu\geq0,\qquad \varepsilon>0,\\
&4dL\nu\leq\mu\varepsilon.
\end{aligned}
\]
The objective and oracle satisfy the following conditions.

\begin{assumption}[Differentiability and smoothness]
The function $f$ is differentiable everywhere, with gradient $\nabla f(x)$ at every $x\in\mathbb{R}^d$, and
\[
\|\nabla f(x)-\nabla f(y)\|\leq L\|x-y\|
\qquad\text{for all }x,y\in\mathbb{R}^d.
\]
\end{assumption}

\begin{assumption}[Attainment, initial gap, and gradient domination]
There exists $x^\star\in\mathbb{R}^d$ such that, for every $x\in\mathbb{R}^d$,
\[
\begin{aligned}
f(x^\star)&\leq f(x),\\
f(x^0)-f(x^\star)&\leq\Delta,\\
2\mu\bigl(f(x)-f(x^\star)\bigr)&\leq\|\nabla f(x)\|^2.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Scalar oracle with blockwise affine drift]
There exist real sequences $(a_j)_{j\geq0}$ and $(b_j)_{j\geq0}$ and functions $e_k:\mathbb{R}^d\to\mathbb{R}$, indexed by $k\geq0$, such that
\[
|e_k(x)|\leq\nu
\qquad\text{for every }k\geq0\text{ and }x\in\mathbb{R}^d.
\]
Calls are indexed starting at zero. Define the block index and position within the block by
\[
\begin{aligned}
j_k&=\left\lfloor\frac{k}{d+2}\right\rfloor,\\
r_k&=k-(d+2)j_k\in\{0,\ldots,d+1\}.
\end{aligned}
\]
At call $k$, a query $x\in\mathbb{R}^d$ returns the scalar
\[
y_k(x)=f(x)+a_{j_k}+b_{j_k}r_k+e_k(x)
\]
for every realization of the oracle randomness. The drift sequences are arbitrary, and the same sequences and error functions govern all queries. Each scalar reply costs one oracle call. Any internal algorithm randomness is independent of the oracle randomness.
\end{assumption}

The algorithm accesses the objective through this oracle and may choose queries adaptively anywhere in $\mathbb{R}^d$. It is selected using only the public inputs. An externally specified budget $K\in\mathbb{N}$ may depend on the full parameter tuple $(d,L,\mu,\varepsilon,x^0,\Delta,\nu)$; every query counts toward this budget and advances the call index.

After $K$ calls, the algorithm returns $\bar{x}\in\mathbb{R}^d$. Writing $\mathbb{P}$ for the joint law of the independent algorithm and oracle randomness, the required accuracy is
\[
f(\bar{x})-f(x^\star)\leq\varepsilon
\qquad\mathbb{P}\text{-almost surely}.
\]
The minimizer appearing in the initial-gap condition can be used here, since all global minimizers have the same objective value.
