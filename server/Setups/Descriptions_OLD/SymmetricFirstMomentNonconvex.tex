\section*{Nonconvex Optimization with Symmetric Noise}
We consider finding an approximately stationary point of a differentiable, possibly nonconvex function $f:\mathbb{R}^d\to\mathbb{R}$, where $d$ is a nonnegative integer and the norm is Euclidean. The gradient is globally Lipschitz, and the initial objective gap to the infimum is bounded. Each oracle call returns unbiased stochastic gradients at two queried points using one shared sample, independently across calls. The noise has symmetric coordinate marginals, bounded first moment, and Lipschitz variation in mean under shared sampling, permitting heavy tails. Given $\varepsilon>0$, success requires a measurable output $\bar{x}$ with integrable gradient norm satisfying $\mathbb{E}\|\nabla f(\bar{x})\|\leq\varepsilon$, averaging over all randomness.

The underlying optimization problem is
\[
\inf_{x\in\mathbb{R}^d} f(x).
\]
The public inputs are the dimension $d\in\{0,1,\ldots\}$, a measurable sample space $\Omega$, an initial point $x^0\in\mathbb{R}^d$, and parameters
\[
L>0,\qquad \Lambda\geq0,\qquad \sigma\geq0,\qquad
\Delta\geq0,\qquad \varepsilon>0.
\]
The objective and its stochastic oracle satisfy the following conditions.

\begin{assumption}[Smoothness and initial gap]
The function $f$ is differentiable everywhere, and, for all $x,y\in\mathbb{R}^d$,
\[
\begin{aligned}
\|\nabla f(x)-\nabla f(y)\| &\leq L\|x-y\|,\\
f(x^0)-f(x) &\leq \Delta.
\end{aligned}
\]
Thus $f(x^0)-\inf_{x\in\mathbb{R}^d}f(x)\leq\Delta$, where the infimum need not be attained.
\end{assumption}

\begin{assumption}[Shared-sample oracle access]
There exist a probability measure $p$ on $\Omega$ and a jointly measurable map $g:\mathbb{R}^d\times\Omega\to\mathbb{R}^d$. Under a probability law $P$ on $\Omega^{\mathbb{N}}$, the coordinate samples $(\xi_k)_{k\geq0}$ are measurable and mutually independent, with
\[
P\circ\xi_k^{-1}=p\qquad\text{for every }k\geq0.
\]
At call $k$, the sole oracle, with ID $0$, accepts any pair $(x,y)\in\mathbb{R}^d\times\mathbb{R}^d$ and returns
\[
\bigl(g(x,\xi_k),g(y,\xi_k)\bigr).
\]
This pair of vector replies costs one oracle call. Queries may be adaptive, and the algorithm's internal randomness is independent of the entire sample sequence.
\end{assumption}

\begin{assumption}[Unbiasedness and first-moment control]
For each $x\in\mathbb{R}^d$, the map $g(x,\cdot)$ is Bochner integrable with respect to $p$, and
\[
\int_{\Omega}g(x,\omega)\,dp(\omega)=\nabla f(x).
\]
Define the noise by $e(x,\omega)=g(x,\omega)-\nabla f(x)$. For every $x,y\in\mathbb{R}^d$,
\[
\begin{aligned}
\int_{\Omega}\|e(x,\omega)\|\,dp(\omega)
&\leq\sigma,\\
\int_{\Omega}\|e(x,\omega)-e(y,\omega)\|\,dp(\omega)
&\leq\Lambda\|x-y\|.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Coordinatewise symmetry]
For every $x\in\mathbb{R}^d$ and coordinate $i\in\{1,\ldots,d\}$, the scalar noise coordinate and its negative have the same law under $p$. Explicitly, for every Borel set $B\subseteq\mathbb{R}$,
\[
p\{\omega:e_i(x,\omega)\in B\}
=
p\{\omega:-e_i(x,\omega)\in B\}.
\]
\end{assumption}

The algorithm is selected using only the public inputs $(d,\Omega,L,\Lambda,\sigma,\Delta,\varepsilon,x^0)$ and accesses the objective through the oracle. The map $g$ and laws $p$ and $P$ are not supplied as public inputs. A call budget $K\in\{0,1,\ldots\}$ may depend on the full public parameter tuple and counts paired queries to oracle $0$.

After at most $K$ calls, the algorithm returns $\bar{x}\in\mathbb{R}^d$. Writing $\mathbb{P}$ for the joint probability law of the algorithm and oracle randomness, the output must be measurable and $\|\nabla f(\bar{x})\|$ must be integrable. The required accuracy is
\[
\int \|\nabla f(\bar{x}(\omega))\|\,d\mathbb{P}(\omega)
\leq\varepsilon.
\]
