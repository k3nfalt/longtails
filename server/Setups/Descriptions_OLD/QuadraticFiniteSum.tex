\section*{Strongly Convex Quadratic Finite Sums}
We minimize the average of $n\geq1$ quadratic functions on a real Hilbert space $E$, possibly infinite dimensional. Each component has a symmetric linear operator of norm at most $L$, and the average has curvature at least $\mu$, where $0<\mu\leq L$. A given point $x^0\in E$ is within $R\geq0$ of a minimizer $x^\star$ whose component gradients have norms at most $G\geq0$. An oracle query specifies a component index and a point, and returns that component's exact gradient. For $\varepsilon>0$, the goal is a point $\bar{x}\in E$ whose expected objective gap from $x^\star$ is at most $\varepsilon$.

Let $A_i:E\to E$ be continuous linear operators and $b_i\in E$ for $i\in\{1,\ldots,n\}$. With the norm induced by the inner product on $E$, the problem is
\[
\min_{x\in E} f(x),\qquad
f(x)=\frac{1}{n}\sum_{i=1}^{n}
\left(\frac{1}{2}\langle x,A_i x\rangle+\langle b_i,x\rangle\right).
\]
The component functions and oracle satisfy the following conditions.

\begin{assumption}[Component operators and average curvature]
Each $A_i$ is symmetric, and, for every $i$ and $x\in E$,
\begin{align*}
\|A_i\|&\leq L,\\
\frac{1}{n}\sum_{i=1}^{n}\langle x,A_i x\rangle&\geq\mu\|x\|^2.
\end{align*}
\end{assumption}

\begin{assumption}[Stationary point and component bounds]
There exists $x^\star\in E$ such that
\begin{align*}
\sum_{i=1}^{n}(A_i x^\star+b_i)&=0,\\
\|x^0-x^\star\|&\leq R,\\
\|A_i x^\star+b_i\|&\leq G
\qquad\text{for every }i.
\end{align*}
The curvature condition makes this stationary point a global minimizer.
\end{assumption}

\begin{assumption}[Exact component oracle]
A query $(i,x)\in\{1,\ldots,n\}\times E$ returns $A_i x+b_i\in E$ at every call index and for every realization of the oracle randomness. Each query costs one oracle call. Algorithm randomness is independent of oracle randomness.
\end{assumption}

The public inputs are $(E,n,L,\mu,R,G,\varepsilon,x^0)$; the component operators and vectors are accessed through oracle queries, which may be chosen adaptively anywhere in $E$. An algorithm selected from these public inputs returns a point $\bar{x}\in E$ after at most $K\in\mathbb{N}$ oracle calls, where the call budget may depend on the public inputs. Writing $\mathbb{P}$ for the joint law of algorithm and oracle randomness, success requires $\bar{x}$ to be measurable, its objective gap to be integrable, and
\[
\int \bigl(f(\bar{x})-f(x^\star)\bigr)\,d\mathbb{P}
\leq\varepsilon.
\]
