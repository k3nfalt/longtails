\section*{Generalized Smooth Composite Optimization}
We consider minimizing $F=f+h$ over a convex set $Q$ in a real Hilbert space $E$, where $f,h:E\to\mathbb{R}$. The function $f$ is convex with continuous gradient, whose variation is controlled by public constants $L_0,L_1$ and gradient norms along segments. The oracle returns exact gradients of $f$, subgradients of $h$ on $Q$ with norm at most $M$, or nearest-point projections onto $Q$. A public initial point $x^0\in Q$ has distance at most $R$ and objective gap at most $\Delta$ from a minimizer $x^\star$, with $\|\nabla f(x^\star)\|\leq G$. Given $\varepsilon>0$, the output $\bar{x}\in Q$ must satisfy $F(\bar{x})-F(x^\star)\leq\varepsilon$ almost surely.

The optimization problem is
\[
\min_{x\in Q} F(x),\qquad F(x)=f(x)+h(x).
\]
The space $E$ may be infinite dimensional, and its norm is induced by its inner product. The public inputs are $(E,L_0,L_1,M,R,\Delta,G,\varepsilon,x^0)$, with
\[
L_0>0,\quad L_1\geq0,\quad M\geq0,\quad R>0,\quad
\Delta>0,\quad G\geq0,\quad \varepsilon>0.
\]
The functions $f,h$ and the feasible set $Q$ are accessed through the oracle described below.

\begin{assumption}[Convexity and differentiability]
The set $Q\subseteq E$ is convex and contains $x^0$. The function $f$ is differentiable everywhere on $E$, its gradient is continuous, and, for every $x,y\in E$ and $t\in[0,1]$,
\[
f((1-t)x+ty)\leq(1-t)f(x)+tf(y).
\]
\end{assumption}

\begin{assumption}[Generalized smoothness]
For every $x,y\in E$ and every $B\in\mathbb{R}$, the segmentwise gradient bound
\[
\|\nabla f(x+t(y-x))\|\leq B
\qquad\text{for every }t\in[0,1]
\]
implies
\[
\|\nabla f(x)-\nabla f(y)\|
\leq (L_0+L_1 B)\|x-y\|.
\]
\end{assumption}

\begin{assumption}[Attainment and initialization]
There exists $x^\star\in Q$ such that
\begin{align*}
F(x^\star)&\leq F(x)\qquad\text{for every }x\in Q,\\
\|x^0-x^\star\|&\leq R,\\
F(x^0)-F(x^\star)&\leq\Delta,\\
\|\nabla f(x^\star)\|&\leq G.
\end{align*}
\end{assumption}

\begin{assumption}[Gradient, subgradient, and projection access]
At every call index and for every realization of oracle randomness, a gradient query at any $x\in E$ returns exactly $\nabla f(x)$. A subgradient query at $u\in Q$ returns a vector $g\in E$ satisfying
\begin{align*}
\|g\|&\leq M,\\
h(u)+\langle g,v-u\rangle&\leq h(v)
\qquad\text{for every }v\in Q.
\end{align*}
A projection query at any $w\in E$ returns a point $z\in E$ satisfying
\begin{align*}
z&\in Q,\\
\|w-z\|&\leq\|w-u\|
\qquad\text{for every }u\in Q.
\end{align*}
Each query of any of these three types costs one oracle call. Subgradient queries outside $Q$ have unrestricted replies. Any internal algorithm randomness is independent of oracle randomness.
\end{assumption}

Queries may be chosen adaptively. Oracle 0 returns gradients of $f$, oracle 1 returns subgradients of $h$, and oracle 2 returns projections onto $Q$. Each query costs one call to the selected oracle, and the three call counts are bounded separately.

For every supplied budget tuple that is at least the proved bounds, the algorithm is executed for a number of calls determined by the public inputs and that tuple. Its output rule returns $\bar{x}\in E$ from the final state. Writing $\mathbb{P}$ for the joint law of algorithm and oracle randomness, success requires a minimizer $x^\star\in Q$ such that
\[
\bar{x}\in Q
\quad\text{and}\quad
F(\bar{x})-F(x^\star)\leq\varepsilon
\qquad\mathbb{P}\text{-almost surely}.
\]
The minimizer witnessing the initialization bounds may be used here, since all minimizers over $Q$ have the same objective value.
