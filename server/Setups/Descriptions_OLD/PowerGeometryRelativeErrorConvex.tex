\section*{Power-Geometry Relative-Error Convex Optimization}
We consider minimizing a differentiable convex function $f:E\to\mathbb{R}$ on a finite-dimensional real normed space $E$, with $L$-Lipschitz derivative, $L>0$. The squared norm centered at an initial point $x^0\in E$ is differentiable and satisfies a power-type Bregman lower bound with exponent $p>2$ and constant $c>0$. Some global minimizer $x^\star$ satisfies $\|x^\star-x^0\|\leq R$, where $R\geq0$. Each oracle call returns a dual vector approximating the derivative with relative error at most $\alpha\in[0,1/4]$. For $\varepsilon>0$, the output $\bar{x}\in E$ must satisfy $f(\bar{x})-f(x^\star)\leq\varepsilon$ almost surely. Only $(E,L,\alpha,p,c,x^0)$ are public algorithm inputs.

The optimization problem is
\[
\min_{x\in E} f(x).
\]
Write $E^*$ for the space of continuous linear functionals on $E$, equipped with the dual norm $\|\cdot\|_*$, and $Df(x)\in E^*$ for the Fr\'echet derivative. The parameters satisfy
\[
L>0,\qquad p>2,\qquad c>0,\qquad
0\leq\alpha\leq\tfrac14,\qquad R\geq0,\qquad\varepsilon>0.
\]
The geometry, objective, and oracle satisfy the following conditions.

\begin{assumption}[Power geometry]
The function $\psi:E\to\mathbb{R}$ defined by
\[
\psi(x)=\frac{\|x-x^0\|^2}{2}
\]
is Fr\'echet differentiable everywhere. For every $x,y\in E$,
\[
\frac{c\|y-x\|^p}
{(\|y-x^0\|+\|x-x^0\|)^{p-2}}
\leq \psi(y)-\psi(x)-D\psi(x)[y-x].
\]
The fraction is defined to be zero when its denominator vanishes, which occurs precisely when $x=y=x^0$.
\end{assumption}

\begin{assumption}[Convexity and smoothness]
The objective $f$ is Fr\'echet differentiable everywhere on $E$. For all $x,y\in E$ and $t\in[0,1]$,
\begin{align*}
f((1-t)x+ty)&\leq(1-t)f(x)+tf(y),\\
\|Df(x)-Df(y)\|_*&\leq L\|x-y\|.
\end{align*}
\end{assumption}

\begin{assumption}[Attainment and initial distance]
There exists $x^\star\in E$ such that
\begin{align*}
f(x^\star)&\leq f(x)\qquad\text{for every }x\in E,\\
\|x^\star-x^0\|&\leq R.
\end{align*}
\end{assumption}

\begin{assumption}[Relative-error derivative access]
The sole oracle, with ID $0$, returns a functional $g_k(x)\in E^*$ at query $x\in E$ and call index $k\in\{0,1,\ldots\}$. For every call index, every query point, and every realization of the oracle randomness,
\[
\|g_k(x)-Df(x)\|_*\leq\alpha\|Df(x)\|_*.
\]
Each query costs one oracle call. The algorithm's internal randomness is independent of the oracle randomness; the oracle randomness may be dependent across calls.
\end{assumption}

The objective is accessed through this oracle, and queries may be chosen adaptively anywhere in $E$. The algorithm is selected using only $(E,L,\alpha,p,c,x^0)$; neither $R$ nor $\varepsilon$ is supplied to it. An externally specified call budget $K\in\mathbb{N}$ may depend on the full parameter tuple $(E,L,\alpha,p,c,x^0,R,\varepsilon)$.

After at most $K$ calls, the algorithm returns $\bar{x}\in E$. Writing $\mathbb{P}$ for the joint law of the independent algorithm and oracle randomness, success requires a global minimizer $x^\star$ such that
\[
f(\bar{x})-f(x^\star)\leq\varepsilon
\qquad\mathbb{P}\text{-almost surely}.
\]
The minimizer witnessing the initial distance bound can be used here, since all global minimizers have the same objective value.
