\section*{Quasar Optimization with Signed Bias}
We consider minimizing a differentiable, possibly nonconvex function $f:E\to\mathbb{R}$ on a real Hilbert space $E$. Its gradient satisfies $\|\nabla f(x)\|\leq M$, and a global minimizer $x^\star$ satisfies $\|x^0-x^\star\|\leq R$ and $\tau(f(x)-f(x^\star))\leq\langle\nabla f(x),x-x^\star\rangle$ for every $x\in E$. Here $x^0\in E$, $M>0$, $R\geq0$, and $\tau\in(0,1]$ are given. Call $k\geq0$ at $x$ returns $(f(x),\nabla f(x)+b_{k+1}-b_k)$, where $(b_k)_{k\geq0}\subset E$ is fixed, $b_0=0$, and $\|b_k\|\leq B$ for a given $B\geq0$. For a given $\varepsilon>0$, the output $\bar{x}\in E$ must satisfy $f(\bar{x})-f(x^\star)\leq\varepsilon$ almost surely.

The optimization problem is
\[
\min_{x\in E} f(x),
\]
where the norm on $E$ is induced by its inner product. The admissible objectives and oracle replies satisfy the following conditions.

\begin{assumption}[Differentiability and bounded gradients]
The function $f$ is differentiable everywhere on $E$, with gradient satisfying
\[
\|\nabla f(x)\|\leq M
\qquad\text{for every }x\in E.
\]
\end{assumption}

\begin{assumption}[Quasar inequality and initial distance]
There exists $x^\star\in E$ such that
\[
\begin{aligned}
f(x^\star)&\leq f(x) &&\text{for every }x\in E,\\
\|x^0-x^\star\|&\leq R,
\end{aligned}
\]
and, relative to this same minimizer,
\[
\tau\bigl(f(x)-f(x^\star)\bigr)
\leq\langle\nabla f(x),x-x^\star\rangle
\qquad\text{for every }x\in E.
\]
\end{assumption}

\begin{assumption}[Exact values and signed gradient bias]
There exists a fixed sequence $(b_k)_{k\geq0}\subset E$ satisfying
\[
b_0=0,\qquad \|b_k\|\leq B\quad\text{for every }k\geq0.
\]
At call index $k$, every query $x\in E$ receives the reply
\[
\bigl(f(x),\nabla f(x)+b_{k+1}-b_k\bigr)
\]
for every realization of the oracle randomness. The same sequence governs all query points and calls. Each reply costs one oracle call. Any internal algorithm randomness is independent of the oracle randomness.
\end{assumption}

The objective is accessed through this oracle, and queries may be chosen adaptively anywhere in $E$. The full tuple $(E,M,B,R,\tau,\varepsilon,x^0)$ is public and may be used to select the algorithm. The objective, the minimizer, and the bias sequence are not supplied as public inputs. An externally specified call budget $K\in\mathbb{N}$ may depend on the full parameter tuple.

After $K$ calls, the algorithm returns $\bar{x}\in E$. Writing $\mathbb{P}$ for the joint law of the independent algorithm and oracle randomness, success requires a global minimizer $x^\star$ such that
\[
f(\bar{x})-f(x^\star)\leq\varepsilon
\qquad\mathbb{P}\text{-almost surely}.
\]
The minimizer witnessing the quasar inequality and initial distance bound can be used here, since all global minimizers have the same objective value.
