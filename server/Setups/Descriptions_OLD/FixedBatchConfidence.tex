\section*{Fixed-Batch Quadratic Confidence Optimization}
We minimize a population quadratic $f:\mathbb{R}^2\to\mathbb{R}$ from an initial point $x^0\in\mathbb{R}^2$. For a probability law $p$ and a hidden center $u\in\mathbb{R}^2$, the objective is $f(x)=\mathbb{E}_{a\sim p}[\langle a,x-u\rangle^2/2]$, where $\|a\|^2\leq L$ almost surely and $\|x^0-u\|\leq R$. An oracle call at $x$ returns $\langle a,x-u\rangle a$ using an independent sample $a\sim p$. Given $\varepsilon>0$ and $\delta\in(0,1)$, the output $\bar{x}$ must satisfy $\mathbb{P}(f(\bar{x})-f(u)>\varepsilon)\leq\delta$. Only $L>0$ and $x^0$ are public algorithm inputs.

The problem is
\[
\min_{x\in\mathbb{R}^2} f(x),
\]
with the Euclidean norm and inner product. The parameters satisfy $L>0$, $R>0$, $\varepsilon>0$, and $0<\delta<1$.

\begin{assumption}[Population quadratic and radius]
There exist a probability law $p$ on $\mathbb{R}^2$ and a point $u\in\mathbb{R}^2$ such that
\[
\begin{aligned}
\|a\|^2 &\leq L \quad p\text{-almost surely},\\
\|x^0-u\| &\leq R,\\
f(x) &= \int_{\mathbb{R}^2}\frac{\langle a,x-u\rangle^2}{2}\,p(da)
\quad\text{for every }x\in\mathbb{R}^2.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Independent oracle samples]
The oracle samples form a measurable sequence $(a_k)_{k\geq 0}$ with a common joint law under which the coordinates are independent and each has law $p$.
\end{assumption}

\begin{assumption}[Oracle access]
At call $k$, a query $x\in\mathbb{R}^2$ receives the vector
\[
\langle a_k,x-u\rangle a_k\in\mathbb{R}^2.
\]
Each reply costs one oracle call. Queries may be chosen adaptively anywhere in $\mathbb{R}^2$, and any algorithm randomness is independent of the oracle samples.
\end{assumption}

The algorithm is selected using only $(L,x^0)$; the law $p$, center $u$, and parameters $R$, $\varepsilon$, and $\delta$ are not supplied to it. An externally specified budget $K\in\mathbb{N}$ may depend on the full parameter tuple. After at most $K$ calls, the algorithm returns a measurable point $\bar{x}\in\mathbb{R}^2$. The population representation makes $u$ a global minimizer. Under the joint law $\mathbb{P}$ of algorithm and oracle randomness, success requires
\[
\mathbb{P}\bigl(f(\bar{x})-f(u)>\varepsilon\bigr)\leq\delta.
\]
