\section*{Gap-Constrained Generalized Smooth Convex Minimization}
We consider minimizing a convex function $f:\mathbb{R}^d\to\mathbb{R}$ in a prescribed high-dimensional regime. The function $f$ is $(L_0,L_1)$-smooth, with $L_0>0$ and $L_1\geq0$, and has a differentiable gradient. A given point $x^0\in\mathbb{R}^d$ satisfies $\|x^0-x^\star\|\leq R$ and $f(x^0)-f(x^\star)\leq\Delta$ for a global minimizer $x^\star$, where $R,\Delta>0$. The oracle returns $\nabla f(x)$ at $x$. Given $\varepsilon>0$, the goal is an output $\bar{x}\in\mathbb{R}^d$ with integrable objective gap satisfying $\mathbb{E}_P[f(\bar{x})-f(x^\star)]\leq\varepsilon$, where $P$ is the law of the algorithm's randomness.

The optimization problem is
\[
\min_{x\in\mathbb{R}^d} f(x).
\]
We use the Euclidean norm, and $\|\cdot\|_{\mathrm{op}}$ denotes its induced operator norm. The parameters satisfy
\[
\begin{aligned}
&d\in\mathbb{N},\qquad L_0>0,\qquad L_1\geq0,\qquad R>0,\\
&0<\varepsilon\leq\frac{L_0R^2}{16},\qquad 16\varepsilon\leq\Delta,\\
&d\geq\left\lceil
2^{80}\left(1+L_1R+\sqrt{\frac{L_0R^2}{\varepsilon}}\right)^{10}
\right\rceil.
\end{aligned}
\]
The algorithm receives $d,L_0,L_1,x^0,R,\Delta$, and $\varepsilon$.

Our assumptions:
\begin{assumption}[Convexity]
For every $x,y\in\mathbb{R}^d$ and $t\in[0,1]$,
\[
f((1-t)x+ty)\leq(1-t)f(x)+tf(y).
\]
\end{assumption}

\begin{assumption}[Generalized smoothness]
The function $f$ is Fr\'echet differentiable everywhere, its gradient is Fr\'echet differentiable everywhere, and
\[
\|\nabla^2 f(x)\|_{\mathrm{op}}
\leq L_0+L_1\|\nabla f(x)\|,
\qquad x\in\mathbb{R}^d.
\]
\end{assumption}

\begin{assumption}[Initial distance and objective gap]
There exists $x^\star\in\mathbb{R}^d$ such that
\[
\begin{aligned}
f(x^\star)&\leq f(x) &&\text{for every }x\in\mathbb{R}^d,\\
\|x^0-x^\star\|&\leq R,\\
f(x^0)-f(x^\star)&\leq\Delta.
\end{aligned}
\]
\end{assumption}

Queries may be made at any point of $\mathbb{R}^d$. After the allotted oracle calls, the output must have an integrable objective gap and satisfy
\[
\mathbb{E}_P\bigl[f(\bar{x})-f(x^\star)\bigr]\leq\varepsilon.
\]
The minimizer $x^\star$ is fixed independently of the algorithm's randomness; all global minimizers have the same objective value.
