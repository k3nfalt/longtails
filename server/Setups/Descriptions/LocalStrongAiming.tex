\section*{Exact Gradients with Local Strong Aiming}
We minimize a differentiable, possibly nonconvex function $f:E\to\mathbb{R}$ on a finite-dimensional real Hilbert space $E$. A global minimizer $x^\star$ defines the solution set $M=\{x:f(x)=f(x^\star)\}$. Within distance $r>0$ of $M$, the gradient is $L$-Lipschitz, a quadratic lower model has coefficient $\sqrt{\mu L}$, and strong aiming toward nearest minimizers has parameter $0<\mu\leq L$. The initial point $x^0\in E$ lies in this neighborhood, with objective gap at most $\Delta\geq0$ satisfying $256\Delta\leq\mu r^2$. Each oracle call returns the exact gradient. For $\varepsilon>0$, the output $\bar{x}\in E$ must satisfy $f(\bar{x})-f(x^\star)\leq\varepsilon$ almost surely. Only $E,L,\mu,x^0$ are public inputs.

The optimization problem is
\[
\min_{x\in E} f(x),
\]
where the norm $\|\cdot\|$ is induced by the inner product $\langle\cdot,\cdot\rangle$. The objective is differentiable everywhere on $E$. For a nonempty set $M\subseteq E$, write
\[
d(x,M)=\inf_{z\in M}\|x-z\|.
\]
The admissible objectives, initialization, and oracle satisfy the following conditions.

\begin{assumption}[Attainment and initialization]
There exists a global minimizer $x^\star\in E$ such that, with $M=\{x\in E:f(x)=f(x^\star)\}$,
\[
\begin{aligned}
f(x^\star)&\leq f(x) &&\text{for every }x\in E,\\
f(x^0)-f(x^\star)&\leq\Delta, & d(x^0,M)&<r.
\end{aligned}
\]
The parameters obey
\[
\begin{aligned}
0<\mu\leq L,\qquad r&>0,\\
\Delta\geq0,\qquad 256\Delta&\leq\mu r^2,\qquad \varepsilon>0.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Local gradient and lower model]
For every $x,y\in E$ with $d(x,M)<r$ and $d(y,M)<r$,
\[
\begin{aligned}
\|\nabla f(x)-\nabla f(y)\|&\leq L\|x-y\|,\\
f(x)+\langle\nabla f(x),y-x\rangle
&\leq f(y)+\sqrt{\mu L}\,\|y-x\|^2.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Strong aiming toward nearest minimizers]
For every $x\in E$ with $d(x,M)<r$ and every $z\in M$ satisfying $\|x-z\|=d(x,M)$,
\[
f(x)-f(x^\star)+\frac{\mu}{2}\|x-z\|^2
\leq\langle\nabla f(x),x-z\rangle.
\]
\end{assumption}

\begin{assumption}[Exact-gradient access]
At every call index and every query point $x\in E$, the oracle returns $\nabla f(x)\in E$ for every realization of its randomness. Each query costs one oracle call. Any internal algorithm randomness is independent of the oracle randomness.
\end{assumption}

The objective is accessed through this oracle, and queries may be chosen adaptively anywhere in $E$. The algorithm is selected using only $(E,L,\mu,x^0)$; the neighborhood radius $r$, initial gap bound $\Delta$, and accuracy level $\varepsilon$ are not supplied to it. An externally specified budget $K\in\mathbb{N}$ may depend on the full parameter tuple $(E,L,\mu,x^0,r,\Delta,\varepsilon)$.

After $K$ oracle calls, the algorithm returns $\bar{x}\in E$. Writing $\mathbb{P}$ for the joint law of the algorithm and oracle randomness, success requires a global minimizer $x^\star$ such that
\[
f(\bar{x})-f(x^\star)\leq\varepsilon
\qquad \mathbb{P}\text{-almost surely}.
\]
Since all global minimizers have the same objective value, the minimizer witnessing the initialization condition may be used in this accuracy criterion.
