\section*{Matrix-Generalized Smooth Zeroth-Order Optimization}
We consider minimizing a convex function $f:\mathbb{R}^d\to\mathbb{R}$, where $d\geq1$, with differentiable gradient and generalized smoothness governed by a hidden positive-definite matrix. Its curvature bound depends on the gradient magnitude in the matrix's dual norm, and the matrix has bounded trace and eigenvalues. A given point $x^0\in\mathbb{R}^d$ has bounded distance and objective gap to a global minimizer $x^\star$. Each oracle call returns the exact scalar value $f(x)$ at its query $x\in\mathbb{R}^d$. For $\varepsilon>0$ and $\delta\in(0,1)$, a measurable output $\bar{x}$ must satisfy $\mathbb{P}(f(\bar{x})-f(x^\star)>\varepsilon)\leq\delta$, where $\mathbb{P}$ denotes the joint randomness law.

Equip $\mathbb{R}^d$ with its Euclidean inner product and norm. The problem is
\[
\min_{x\in\mathbb{R}^d} f(x).
\]
The public parameters are $(d,L_0,L_1,r,R,\Delta,\varepsilon,\delta,x^0)$, with
\[
\begin{aligned}
&d\in\mathbb{N},\quad d\geq1,\quad x^0\in\mathbb{R}^d,\\
&L_0>0,\quad L_1\geq0,\quad r>0,\quad R>0,\quad \Delta>0,\\
&\varepsilon>0,\quad 0<\delta<1.
\end{aligned}
\]
The objective and its oracle satisfy the following conditions.

\begin{assumption}[Convexity and differentiability]
The function $f$ is differentiable everywhere, and its gradient $\nabla f:\mathbb{R}^d\to\mathbb{R}^d$ is differentiable everywhere. For every $x,y\in\mathbb{R}^d$ and $t\in[0,1]$,
\[
f((1-t)x+ty)\leq(1-t)f(x)+tf(y).
\]
\end{assumption}

\begin{assumption}[Hidden matrix generalized smoothness]
There exist a symmetric matrix $H\in\mathbb{R}^{d\times d}$ and a scalar $\mu>0$ such that, for every $v\in\mathbb{R}^d$,
\[
\begin{aligned}
\mu\|v\|^2&\leq\langle Hv,v\rangle\leq\|v\|^2,\\
\operatorname{tr}(H)&\leq r.
\end{aligned}
\]
For $g\in\mathbb{R}^d$ and $c\in\mathbb{R}$, say that $c$ certifies $g$ if
\[
\begin{aligned}
c&\geq0,\\
\langle g,u\rangle&\leq c\sqrt{\langle Hu,u\rangle}
\qquad\text{for every }u\in\mathbb{R}^d.
\end{aligned}
\]
Equivalently, this means $c\geq\sqrt{\langle H^{-1}g,g\rangle}$. For every $x\in\mathbb{R}^d$, every $c$ certifying $\nabla f(x)$, and every $v,w\in\mathbb{R}^d$, the derivative $D(\nabla f)(x)$ satisfies
\[
\begin{aligned}
\langle D(\nabla f)(x)v,w\rangle
&\leq (L_0+L_1c)\\
&\quad\cdot\sqrt{\langle Hv,v\rangle}\sqrt{\langle Hw,w\rangle}.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Attainment and initialization]
There exists $x^\star\in\mathbb{R}^d$ such that
\[
\begin{aligned}
f(x^\star)&\leq f(x)\qquad\text{for every }x\in\mathbb{R}^d,\\
\|x^0-x^\star\|&\leq R,\\
f(x^0)-f(x^\star)&\leq\Delta.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Exact function-value access]
At every call index and every query $x\in\mathbb{R}^d$, the oracle returns the scalar $f(x)$ for every realization of its randomness. Each query costs one oracle call. Any internal algorithm randomness is independent of the oracle randomness.
\end{assumption}

The algorithm accesses $f$ through this oracle and may choose queries adaptively anywhere in $\mathbb{R}^d$. It is selected using only the public parameter tuple; the witnesses $H$, $\mu$, and $x^\star$ are not supplied. An externally specified budget $K\in\mathbb{N}$ may depend on the full public tuple and counts every function-value query.

After $K$ calls, the output $\bar{x}\in\mathbb{R}^d$ must be measurable under the joint law $\mathbb{P}$ of the algorithm and oracle randomness and satisfy
\[
\mathbb{P}\bigl(f(\bar{x})-f(x^\star)>\varepsilon\bigr)\leq\delta.
\]
Here the minimizer witnessing initialization may be used, since all global minimizers have the same objective value.
