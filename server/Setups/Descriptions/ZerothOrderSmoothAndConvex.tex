\section*{Smooth Convex Zeroth-Order Optimization}
We consider minimizing a differentiable convex function $f:E\to\mathbb{R}$ on a $d$-dimensional real Hilbert space $E$, where $d\geq 1$, with $L$-Lipschitz gradient for $L>0$. A given point $x^0\in E$ is within distance $R\geq 0$ of a global minimizer $x^\star$. Each oracle call returns an unbiased scalar estimate of the queried function value, with variance at most $\sigma^2$ for $\sigma\geq 0$, using an independent sample. For $\varepsilon>0$, the required measurable output $\bar{x}\in E$ has integrable objective gap and satisfies $\mathbb{E}[f(\bar{x})-f(x^\star)]\leq\varepsilon$, where expectation includes oracle and algorithm randomness.

The optimization problem is
\begin{equation}
\label{eq:problem}
\min_{x\in E} f(x),
\end{equation}
where $E$ is linearly isometric to $\mathbb{R}^d$ with its Euclidean norm, and is equipped with its Borel sigma-algebra. The public inputs are $E$, a measurable sample space $\Omega$, the dimension $d\in\mathbb{N}$ with $d>0$, the constants $L>0$, $R\geq 0$, $\sigma\geq 0$, and $\varepsilon>0$, and the initial point $x^0\in E$. The admissible objectives and oracle access satisfy the following conditions.

\begin{assumption}[Convexity and smoothness]
The function $f$ is differentiable everywhere on $E$, and, for every $x,y\in E$ and $t\in[0,1]$,
\begin{align}
f((1-t)x+ty) &\leq (1-t)f(x)+tf(y),\\
\|\nabla f(x)-\nabla f(y)\| &\leq L\|x-y\|.
\end{align}
\end{assumption}

\begin{assumption}[Attainment and initial distance]
There exists $x^\star\in E$ such that
\begin{align}
f(x^\star) &\leq f(x) \qquad \text{for every }x\in E,\\
\|x^0-x^\star\| &\leq R.
\end{align}
\end{assumption}

\begin{assumption}[Independent scalar oracle]
There exist a probability measure $p$ on $\Omega$, a probability measure $P$ on $\Omega^{\mathbb{N}}$, and a jointly measurable function $g:E\times\Omega\to\mathbb{R}$. Under $P$, the coordinate samples $\xi_k(\omega)=\omega_k$, $k\in\mathbb{N}$, are mutually independent and satisfy
\begin{equation}
P\circ\xi_k^{-1}=p \qquad \text{for every }k\in\mathbb{N}.
\end{equation}
At call $k$, a query $x\in E$ returns the scalar $g(x,\xi_k)$ and costs one oracle call. Any internal algorithm randomness is independent of the entire sample sequence.
\end{assumption}

\begin{assumption}[Unbiasedness and bounded variance]
For every $x\in E$, both $g(x,\cdot)$ and $(g(x,\cdot)-f(x))^2$ are integrable with respect to $p$, and
\begin{align}
\int_{\Omega} g(x,z)\,dp(z) &= f(x),\\
\int_{\Omega} (g(x,z)-f(x))^2\,dp(z) &\leq \sigma^2.
\end{align}
\end{assumption}

The objective is accessed through this scalar oracle. Queries may be chosen adaptively anywhere in $E$. The algorithm is selected using only the public inputs $(E,\Omega,d,L,R,\sigma,\varepsilon,x^0)$; the objective, a minimizing point, the oracle function, and the sampling laws are not supplied to it. An externally specified budget $K\in\mathbb{N}$ may depend on the full public parameter tuple. Every scalar evaluation counts separately, including repeated evaluations at the same point.

After $K$ calls, the algorithm returns $\bar{x}\in E$. Let $\mathbb{P}$ denote the joint law of the independent algorithm randomness and oracle sample sequence. Success requires $\bar{x}$ to be measurable and, for some global minimizer $x^\star$, the map $\omega\mapsto f(\bar{x}(\omega))-f(x^\star)$ to be integrable with respect to $\mathbb{P}$, with
\begin{equation}
\label{eq:accuracy}
\int \bigl(f(\bar{x}(\omega))-f(x^\star)\bigr)\,d\mathbb{P}(\omega)
\leq \varepsilon.
\end{equation}
All global minimizers have the same objective value, so the minimizer witnessing the initial distance bound may also be used in \eqref{eq:accuracy}.
