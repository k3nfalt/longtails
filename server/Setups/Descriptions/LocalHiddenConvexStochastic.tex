\section*{Locally Hidden Convex Stochastic Optimization}
We consider minimizing $F:E\to\mathbb{R}$ on a finite-dimensional real Hilbert space $E$. Its gradient is $L$-Lipschitz, where $L>0$, and a global minimizer $x^\star$ lies within distance $R>0$ of an initial point $x^0\in E$. Locally, $F$ is a differentiable convex function composed with a hidden differentiable map whose derivative is uniformly nonsingular and varies slowly. Each oracle call returns an independent-sample unbiased gradient estimate with variance at most $\sigma^2$, where $\sigma\geq0$. For $\varepsilon>0$, success requires a measurable random output $\bar{x}\in E$ with integrable objective gap and $\mathbb{E}[F(\bar{x})-F(x^\star)]\leq\varepsilon$, where expectation includes oracle and algorithm randomness.

The optimization problem is
\[
\min_{x\in E} F(x),
\]
with the norm on $E$ induced by its inner product. The public inputs are $E$, a measurable sample space $\Omega$, $L$, $R$, $\sigma$, and $x^0$. The additional parameters $\mu$, $L_J$, and $\varepsilon$ are hidden from the algorithm and satisfy
\[
\mu>0,\qquad L_J\geq0,\qquad 32L_JR\leq\mu.
\]
Write $B(x,r)=\{y\in E:\|y-x\|<r\}$ and $\overline{B}(x,r)=\{y\in E:\|y-x\|\leq r\}$. The objective, its local representation, and the oracle satisfy the following conditions.

\begin{assumption}[Global smoothness]
The function $F$ is differentiable everywhere, and
\[
\|\nabla F(x)-\nabla F(y)\|\leq L\|x-y\|
\qquad\text{for all }x,y\in E.
\]
\end{assumption}

\begin{assumption}[Local hidden convexity]
There exist functions $H:E\to\mathbb{R}$ and $c:E\to E$, an open convex set $U\subseteq E$, and a map $J:E\to\mathcal{L}(E,E)$, where $\mathcal{L}(E,E)$ denotes the continuous linear operators equipped with the operator norm. The function $H$ is differentiable on $U$ and satisfies
\[
H((1-t)u+tv)\leq(1-t)H(u)+tH(v)
\qquad(u,v\in U,\ t\in[0,1]).
\]
The local representation and derivative conditions are
\[
\begin{aligned}
F(x)&=H(c(x))
&&\text{for }x\in B(x^0,3R),\\
c(x)&\in U,\qquad Dc(x)=J(x)
&&\text{for }x\in\overline{B}(x^0,2R),\\
\|J(x)v\|&\geq\mu\|v\|
&&\text{for }x\in\overline{B}(x^0,2R),\ v\in E.
\end{aligned}
\]
Moreover, for every $x,y\in\overline{B}(x^0,2R)$,
\[
\|J(x)-J(y)\|\leq L_J\|x-y\|.
\]
\end{assumption}

\begin{assumption}[Attainment and initial distance]
There exists $x^\star\in E$ such that
\[
\begin{aligned}
F(x^\star)&\leq F(x) &&\text{for every }x\in E,\\
\|x^0-x^\star\|&\leq R.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Stochastic-gradient access]
There exist a probability measure $p$ on $\Omega$ and a jointly measurable map $g:E\times\Omega\to E$. For every fixed $x\in E$, the map $g(x,\cdot)$ is Bochner integrable and the map $\omega\mapsto\|g(x,\omega)-\nabla F(x)\|^2$ is integrable with respect to $p$. They satisfy
\[
\begin{aligned}
\int_{\Omega}g(x,\omega)\,dp(\omega)&=\nabla F(x),\\
\int_{\Omega}\|g(x,\omega)-\nabla F(x)\|^2\,dp(\omega)&\leq\sigma^2.
\end{aligned}
\]
At call $k\in\{0,1,\ldots\}$, oracle $0$ returns $g(x,\xi_k)\in E$ at the queried point $x$, where the samples $\xi_k$ are independent with common law $p$. Each query costs one call. Any internal algorithm randomness is independent of the entire sample sequence.
\end{assumption}

Queries may be chosen adaptively anywhere in $E$. The algorithm accesses the objective through oracle $0$ and is selected using only the public inputs $(E,\Omega,L,R,\sigma,x^0)$. The functions $F,H,c,J$, the set $U$, and the oracle representation $(g,p)$ are not supplied as additional inputs. An externally specified call budget $K\in\mathbb{N}$ may depend on the full parameter tuple, including $\mu$, $L_J$, and $\varepsilon$.

After at most $K$ calls, the algorithm returns a point $\bar{x}\in E$. Let $\mathbb{P}$ denote the joint probability law of the algorithm and oracle randomness. Success requires that $\bar{x}$ be measurable and that there exist a global minimizer $x^\star$ for which the objective gap is integrable with respect to $\mathbb{P}$ and
\[
\int \bigl(F(\bar{x}(\omega))-F(x^\star)\bigr)\,d\mathbb{P}(\omega)
\leq\varepsilon.
\]
The minimizer witnessing the initial distance bound can be used here, since all global minimizers have the same objective value.
