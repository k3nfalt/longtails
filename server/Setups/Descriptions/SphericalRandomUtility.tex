\section*{Spherical Random Utility Comparisons}
We minimize a function $f:\mathbb{R}^d\to\mathbb{R}$ that is convex on the closed Euclidean ball $K$ of radius $R>0$ centered at the origin, where $d\geq 2$. For each ordered pair in $K$, the oracle independently draws a spherically symmetric vector $Z$ from a common law and reports whether the first point has at least as large a utility $u_Z(x)=f(x)+\langle Z,x\rangle$ as the second. With probability at least $1/2$, $u_Z$ is $B$-Lipschitz on $K$, where $B>0$. The goal is a feasible output with integrable objective gap and expected gap at most $\varepsilon$, for $0<\varepsilon\leq BR/16$.

The optimization problem is
\[
\min_{x\in K} f(x),
\qquad K=\{x\in\mathbb{R}^d:\|x\|_2\leq R\}.
\]
The algorithm receives the integer dimension $d$, the radius $R$, the bound $B$, and the tolerance $\varepsilon$.

Our assumptions:
\begin{assumption}[Convexity on the ball]
For every $x,y\in K$ and $t\in[0,1]$,
\[
f((1-t)x+ty)\leq (1-t)f(x)+t f(y).
\]
\end{assumption}

\begin{assumption}[Spherical perturbations and Lipschitz utilities]
The perturbation law $\mu$ is a probability measure on $\mathbb{R}^d$. For every orthogonal transformation $U$ and every Borel set $A\subseteq\mathbb{R}^d$, it satisfies $\mu(U^{-1}A)=\mu(A)$. Define the set of perturbations
\[
G=\bigl\{z\in\mathbb{R}^d: |u_z(x)-u_z(y)|\leq B\|x-y\|_2
\text{ for all }x,y\in K\bigr\}.
\]
Then $\mu(G)\geq 1/2$.
\end{assumption}

For an ordered query $(x,y)\in K\times K$, the comparison bit is
\[
c(x,y,z)=\mathbf{1}\{u_z(y)\leq u_z(x)\}.
\]
The map $c$ is jointly measurable on $K\times K\times\mathbb{R}^d$. On call $k$, the oracle returns $c(x,y,Z_k)$, where the $Z_k$ are independent random vectors with law $\mu$ and the entire sequence is independent of the algorithm's randomness.

After the allotted calls, the algorithm must return $\bar{x}\in K$. There must exist a minimizer $x^\star\in\operatorname*{arg\,min}_{x\in K} f(x)$ for which the gap $f(\bar{x})-f(x^\star)$ is integrable and
\[
\mathbb{E}\bigl[f(\bar{x})-f(x^\star)\bigr]\leq\varepsilon,
\]
where the expectation is over the algorithm's randomness and the oracle perturbations.
