\section*{Convex Ball-Proximal Optimization}
We consider minimizing a convex function $f:E\to\mathbb{R}$ over a convex set $C$ in a finite-dimensional real inner-product space $E$, with closed epigraph over $C$. An initial point $x^0\in C$ satisfies $\|x^0-x^\star\|\leq R$ and $f(x^0)-f(x^\star)\leq\Delta$ for some minimizer $x^\star\in C$, where $R\geq0$ and $\Delta>0$. Given $t>0$, each oracle call at $x\in C$ returns an exact minimizer over $C\cap\{z:\|z-x\|\leq t\}$. The required final iterate $\bar{x}\in C$ satisfies $f(\bar{x})-f(x^\star)\leq\varepsilon$ almost surely, where $\varepsilon>0$.

The constrained problem is
\[
\min_{x\in C} f(x),
\]
where the norm on $E$ is induced by its inner product. The public inputs are $(E,t,R,\Delta,\varepsilon,x^0)$; the set $C$ and objective $f$ are accessed through the oracle. The admissible instances satisfy the following conditions.

\begin{assumption}[Convexity and closed epigraph]
The set $C\subseteq E$ is convex, and for all $x,y\in C$ and $\lambda\in[0,1]$,
\[
f((1-\lambda)x+\lambda y)
\leq (1-\lambda)f(x)+\lambda f(y).
\]
The restricted epigraph
\[
\{(x,a)\in E\times\mathbb{R}:x\in C,\ f(x)\leq a\}
\]
is closed in $E\times\mathbb{R}$.
\end{assumption}

\begin{assumption}[Attainment and initialization]
The initial point belongs to $C$, and there exists $x^\star\in C$ such that
\begin{align*}
f(x^\star) &\leq f(x) &&\text{for every }x\in C,\\
\|x^0-x^\star\| &\leq R,\\
f(x^0)-f(x^\star) &\leq\Delta.
\end{align*}
\end{assumption}

\begin{assumption}[Exact ball-minimization oracle]
At every call index, every query $x\in C$, and every realization of oracle randomness, oracle $0$ returns a point $y\in E$ satisfying
\begin{align*}
y &\in C,\\
\|y-x\| &\leq t,\\
f(y) &\leq f(z)
&&\text{for every }z\in C\text{ with }\|z-x\|\leq t.
\end{align*}
Each query costs one call to oracle $0$. The oracle may select any point satisfying these conditions.
\end{assumption}

The permitted algorithm starts at $x^0$, queries its current point, and replaces that point by the oracle reply. For a call budget $K\in\mathbb{N}$, its iterates and output are
\begin{align*}
x^{k+1} &= \text{the reply of oracle }0\text{ at }x^k,
&&k=0,\ldots,K-1,\\
\bar{x} &= x^K.
\end{align*}
Thus every query is feasible, and the execution uses exactly $K$ oracle calls. The budget may depend on the public inputs. The update rule is fixed and uses only the initial point and successive replies. Any internal algorithm randomness is independent of oracle randomness.

Writing $\mathbb{P}$ for the joint probability law, success requires a minimizer $x^\star\in C$ such that
\[
\bar{x}\in C
\quad\text{and}\quad
f(\bar{x})-f(x^\star)\leq\varepsilon
\qquad \mathbb{P}\text{-almost surely}.
\]
The output is the final iterate. Since all minimizers over $C$ have the same objective value, the minimizer witnessing the initialization bounds can also be used in this accuracy criterion.
