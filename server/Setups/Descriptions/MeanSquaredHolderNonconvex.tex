\section*{Nonconvex Optimization with Paired Stochastic Gradients}
We consider minimizing a differentiable, possibly nonconvex function $f:E\to\mathbb{R}$ on a separable real Hilbert space $E$. Its gradient is Lipschitz, and its objective gap from a given initial point $x^0\in E$ is globally bounded. Each oracle call returns two unbiased stochastic gradients at queried points, evaluated using the same random sample; samples are independent across calls. The stochastic gradients have bounded variance and satisfy a mean-squared H\"older condition with exponent $\nu\in[1/2,1]$. For a prescribed tolerance $\varepsilon>0$, the goal is a measurable random output $\bar{x}\in E$ with integrable gradient norm satisfying $\mathbb{E}\|\nabla f(\bar{x})\|\leq\varepsilon$, where expectation includes oracle and algorithm randomness.

The underlying optimization problem is
\[
\inf_{x\in E} f(x),
\]
where the norm on $E$ is induced by its inner product and $E$ carries its Borel sigma-algebra. The public inputs are $E$, a measurable sample space $\Omega$, the initial point $x^0$, and the parameters
\[
L>0,\qquad M\geq0,\qquad \nu\in[1/2,1],\qquad
\sigma\geq0,\qquad \Delta\geq0,\qquad \varepsilon>0.
\]
The objective and oracle satisfy the following conditions.

\begin{assumption}[Smoothness and initial gap]
The function $f$ is differentiable everywhere on $E$. For every $x,y\in E$,
\[
\begin{aligned}
\|\nabla f(x)-\nabla f(y)\| &\leq L\|x-y\|,\\
f(x^0)-f(x) &\leq \Delta.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Unbiased stochastic gradients]
There exist a probability measure $p$ on $\Omega$ and a jointly measurable map $g:E\times\Omega\to E$. For every $x\in E$, the map $g(x,\cdot)$ is Bochner integrable under $p$, the function $\omega\mapsto\|g(x,\omega)-\nabla f(x)\|^2$ is integrable under $p$, and
\[
\begin{aligned}
\int_{\Omega} g(x,\omega)\,dp(\omega) &= \nabla f(x),\\
\int_{\Omega}\|g(x,\omega)-\nabla f(x)\|^2\,dp(\omega) &\leq \sigma^2.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Mean-squared H\"older regularity]
For every $x,y\in E$, the function $\omega\mapsto\|g(x,\omega)-g(y,\omega)\|^2$ is integrable under $p$ and satisfies
\[
\int_{\Omega}\|g(x,\omega)-g(y,\omega)\|^2\,dp(\omega)
\leq M\|x-y\|^{2\nu}.
\]
\end{assumption}

\begin{assumption}[Paired oracle access and independent sampling]
Let $P$ be a probability measure on $\Omega^{\mathbb{N}}$. The coordinate samples $\xi_k:\Omega^{\mathbb{N}}\to\Omega$, for $k=0,1,\ldots$, are measurable, mutually independent under $P$, and each has distribution $p$. At call $k$, the sole oracle, with ID $0$, accepts any pair $(x,y)\in E\times E$ and returns
\[
\bigl(g(x,\xi_k),\,g(y,\xi_k)\bigr)\in E\times E.
\]
This paired reply costs one oracle call. Query pairs may be chosen adaptively anywhere in $E\times E$. Internal algorithm randomness is independent of the entire oracle sample sequence.
\end{assumption}

The algorithm accesses the objective through this oracle and is selected using the public inputs $(E,\Omega,L,M,\nu,\sigma,\Delta,\varepsilon,x^0)$. The function $f$, the map $g$, and the laws $p$ and $P$ are not supplied as public inputs. A call budget $K\in\mathbb{N}$ may depend on the full public parameter tuple and counts paired replies.

After at most $K$ calls, the algorithm must return a point $\bar{x}\in E$. Let $\mathbb{P}$ denote the joint probability law of algorithm and oracle randomness on a measurable space $\Theta$. Success requires that $\bar{x}:\Theta\to E$ be measurable, that $\theta\mapsto\|\nabla f(\bar{x}(\theta))\|$ be integrable under $\mathbb{P}$, and that
\[
\int_{\Theta}\|\nabla f(\bar{x}(\theta))\|\,d\mathbb{P}(\theta)
\leq\varepsilon.
\]
