\section*{Cohypomonotone Equations with Adjoint Access}
We consider finding a zero of a differentiable map $F:E\to E$ on a finite-dimensional real inner product space $E$. The map is $L$-Lipschitz, its derivative $DF$ is $L_2$-Lipschitz, and it is $\rho$-cohypomonotone, where $L>0$ and $L_2,\rho\geq0$. An initial point $x^0\in E$ lies within distance $R\geq0$ of a zero $x^\star$. Each oracle call returns either $F(x)$ or the adjoint product $DF(x)^*w$ for queried $x,w\in E$. For $\varepsilon>0$, the output $\bar{x}\in E$ must satisfy $\|F(\bar{x})\|\leq\varepsilon$ almost surely. Only $E,L,L_2,\rho,x^0$ are public inputs; $R$ and $\varepsilon$ are not supplied to the algorithm.

The equation to be solved is
\[
F(x)=0,\qquad x\in E,
\]
where $\langle\cdot,\cdot\rangle$ denotes the inner product and $\|\cdot\|$ its induced norm. For linear maps on $E$, the same norm notation denotes the induced operator norm. The admissible maps and oracle access satisfy the following conditions.

\begin{assumption}[Differentiability and smoothness]
The map $F$ is Fr\'echet differentiable at every point of $E$. Writing $J(x)=DF(x)$, for every $x,y\in E$,
\[
\begin{aligned}
\|F(x)-F(y)\| &\leq L\|x-y\|,\\
\|J(x)-J(y)\| &\leq L_2\|x-y\|.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Cohypomonotonicity]
For every $x,y\in E$,
\[
\langle F(x)-F(y),x-y\rangle
\geq -\rho\|F(x)-F(y)\|^2.
\]
\end{assumption}

\begin{assumption}[Existence of a nearby zero]
There exists $x^\star\in E$ such that
\[
\begin{aligned}
F(x^\star)&=0,\\
\|x^0-x^\star\|&\leq R.
\end{aligned}
\]
\end{assumption}

\begin{assumption}[Exact value and adjoint access]
A value query at $x\in E$ returns $F(x)\in E$. An adjoint query at $(x,w)\in E\times E$ returns $J(x)^*w\in E$, characterized by
\[
\langle J(x)^*w,h\rangle=\langle w,J(x)h\rangle
\qquad\text{for every }h\in E.
\]
These replies are exact at every call index and for every realization of the oracle randomness. Each query of either kind costs one oracle call. Any internal algorithm randomness is independent of the oracle randomness.
\end{assumption}

The map is accessed through this oracle, with adaptive queries permitted anywhere in $E$ and arbitrary adjoint-query vectors in $E$. The algorithm is selected using only the public inputs $(E,L,L_2,\rho,x^0)$. An externally specified budget $K\in\mathbb{N}$ may depend on the full parameter tuple $(E,L,L_2,\rho,x^0,R,\varepsilon)$ and counts both kinds of oracle calls.

After $K$ calls, the algorithm returns $\bar{x}\in E$. Writing $\mathbb{P}$ for the joint law of the algorithm and oracle randomness, the required accuracy is
\[
\|F(\bar{x})\|\leq\varepsilon
\qquad\mathbb{P}\text{-almost surely}.
\]
